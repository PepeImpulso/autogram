# v1.20.4

Android Auto hotfix release focused on launcher visibility in the real car.

## Fixed

- Restored the `IOT` car-app category alongside `NAVIGATION` on
  `AutogramCarAppService`. Real-car testing showed that removing `IOT`
  fixed the wrong messaging surface but also made the app disappear from the
  Android Auto launcher entirely on this setup.
- `MESSAGING` stays removed, so taps should no longer be hijacked into
  Android Auto's empty inbox screen.
