# v1.20.4 — Android Auto launcher visibility hotfix 🚗🩹

Focused follow-up release after real-car testing showed that v1.20.3
fixed the wrong Android Auto surface but also made Autogram disappear
from the launcher entirely on this head unit / Gearhead combination.

## 🐛 Fixed

- **Restored launcher discovery on the real car.** `AutogramCarAppService`
  now declares `IOT` alongside `NAVIGATION` again. Removing `IOT` solved
  the old “No messages received while driving” hijack, but it also stopped
  the Android Auto launcher from surfacing the app tile on the user's
  actual car, which is a slightly dramatic interpretation of “bug fix.”

- **Kept the messaging hijack fix in place.** `MESSAGING` remains removed,
  so Gearhead should stop routing taps into Android Auto's built-in empty
  messaging inbox instead of opening Autogram's custom surface.

## 🧪 Tests

- **Unit tests passed.** `:app:testDebugUnitTest`
- **Debug APK built successfully.** `:app:assembleDebug`
- **Release APK built successfully.** `:app:assembleRelease`

## Install

Update from 1.20.3. Reconnect to the car and check whether Autogram is
back in the Android Auto launcher; if it is, tapping it should now open
Autogram rather than the empty messaging screen.
