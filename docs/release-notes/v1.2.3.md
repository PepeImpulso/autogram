# v1.2.3 — Playback polish 🔊

## ✨ Added

- **Interrupción al grabar**: si estás escuchando un reply de Merlin
  y pulsas el micro para grabar, el playback se corta
  inmediatamente — antes se quedaba sonando en paralelo con el
  beep de start.
- **Start/end cues**: dos beeps distintos (subida/bajada de tono)
  para marcar inicio y fin de grabación, en vez de un solo beep
  ambiguo.
- **Playback speed slider** en Ajustes → Reproducción: 0.5x a 2.0x
  con step de 0.25x, aplicado a audio y a TTS.
