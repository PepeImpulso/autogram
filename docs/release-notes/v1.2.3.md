# v1.2.3 — Playback polish 🔊

## ✨ Added

- **Interrupt-on-record**: if you're listening to a reply from
  Merlin and tap the mic to record, playback cuts off instantly —
  previously it kept playing in parallel with the start beep.
- **Start/end cues**: two distinct beeps (rising/falling tone) to
  mark the start and end of a recording, instead of one ambiguous
  beep.
- **Playback speed slider** in Settings → Playback: 0.5x to 2.0x
  in 0.25x steps, applied to both audio and TTS.
