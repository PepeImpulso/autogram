# v1.32.2 — Correct recording artwork and playback diagnostics 🚗

This update keeps the selected recipient visible on Android Auto's recording
card and adds diagnostics for the reported voice and speed differences.

## 🐛 Fixed

- **Recording shows the selected recipient's artwork (#6).** The previous
  sender's idle card is replaced immediately when recording starts. The
  recipient's own artwork then appears, and a delayed artwork load cannot
  overwrite a recording that has already ended or changed target.

## 🔧 Internal

- **Playback-path diagnostics for issue #5.** Logs identify whether an
  incoming item used original audio, summary speech, or text speech, with
  the requested playback speed. No voice or speed behavior was changed
  without a confirmed reproduction.

## 🧪 Tests

- The full local GitHub-debug unit test suite passes, including a guard
  against applying stale recipient artwork to another recording.

## Install

Update through Autogram's in-app updater. In Android Auto, check that the
recording card keeps the selected recipient's photo; compare the affected
contacts with Trinity for the separate voice/speed investigation.
