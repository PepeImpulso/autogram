# v1.3.0 — Selector de idioma + i18n a 6 locales 🌐

## ✨ Added

- **Selector de idioma** en Ajustes → General → Idioma. Aplicación
  inmediata via `AppCompatDelegate.setApplicationLocales` — recrea
  las Activities para que el cambio se vea sin reiniciar.
- **Traducciones** a los 6 idiomas: Español (origen), Inglés,
  Francés, Alemán, Chino simplificado, Japonés. Todas las strings
  de UI pasaron de `values/` a `values-<locale>/strings.xml`.

## 🔍 Changed

- Arquitectura preparada para añadir nuevos idiomas cambiando solo
  el `strings.xml` correspondiente — sin tocar código Kotlin.

## Install

Actualización desde 1.2.x. Al abrir por primera vez tras update se
muestra el idioma del sistema; puedes cambiarlo en Ajustes.
