# v1.3.0 — Language selector + i18n across 6 locales 🌐

## ✨ Added

- **Language selector** in Settings → General → Language. Applied
  immediately via `AppCompatDelegate.setApplicationLocales` —
  recreates the Activities so the change is visible without
  restarting.
- **Translations** to the 6 languages: Spanish (source), English,
  French, German, Simplified Chinese, Japanese. All UI strings
  moved from `values/` to `values-<locale>/strings.xml`.

## 🔍 Changed

- Architecture ready to add new languages by only changing the
  corresponding `strings.xml` — no Kotlin code changes required.

## Install

Update from 1.2.x. On first open after the update the system
language is shown; you can change it in Settings.
