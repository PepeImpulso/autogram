# v1.30.3 — Bigger contacts again, pending count that clears 👥

Brings back the large two-per-row secondary contacts and fixes a pending
count that stayed after its message had been heard.

## 🐛 Fixed

- **"1 Pending" stayed after the message played.** Playing a queued message
  some other way (the replay button, History) marked it as heard but left
  it in the in-memory queue, so the pill kept counting it. Hearing a
  message now removes it from the queue as well.
- **Controls could stay on after a replay ended.** When a manually played
  message finished while other messages were waiting, Home kept showing it
  as playing (pause, next and stop visible with nothing playing). It now
  goes back to the pending count.
- **Secondary contacts were smaller than before.** v1.30.1 shrank them so
  three fit on one row, because on short screens the wrapped row was cut
  off. Home now picks the largest size that fits: on tall phones that is
  two per row with the third below, as before; short screens use one row.

## Install

Update through Autogram's in-app updater.
