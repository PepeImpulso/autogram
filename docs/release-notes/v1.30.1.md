# v1.30.1 — Playback controls that stay put ⏯️

Fixes found by testing v1.30.0's pause and next buttons on a phone, with
several contacts and back-to-back messages.

## 🐛 Fixed

- **Controls disappeared while messages were queued.** When a new message
  arrived during playback, the queue counter replaced the "playing" state.
  Home then hid the pause, next and stop buttons and the playing ring, even
  though audio was still playing. Queuing a message now leaves the playing
  or paused state alone, and the pending count still updates.
- **Pause / next moved under the thumb.** In the header, the buttons shifted
  sideways whenever the "N Pending" pill appeared or went away, so a tap
  meant for pause could land on stop. They now sit in a fixed bar above
  the bottom menu, showing who is playing and with larger buttons.
- **Pausing a text message read aloud now works.** Before, pausing a text
  message ended playback and sent it back to the queue, with no way to
  resume. It now shows as paused: Resume reads it again from the start
  (Android's text-to-speech cannot continue mid-sentence), and Next drops it.
- **Third secondary contact missing on Home.** With 3 or more secondary
  contacts, their size did not count the ring around each circle, so the
  last one wrapped onto a row with no room and was not shown. All of them
  now fit.

## Install

Update through Autogram's in-app updater.
