# v1.3.2 — Polish pre-roadmap 🧹

## 🐛 Fixed

- **Crash en arranque** en `Application.attachBaseContext`: el code
  path de locale intentaba leer `applicationContext` antes de estar
  disponible, crasheando con NPE en algunos arranques en frío.
  Movido el bootstrap de locale a después de `super.onCreate()`.

## ✨ Added

- **Zoom de foto al tap** en Manage Pinned: toca la foto circular
  de un círculo y la ves a pantalla completa con pinch-to-zoom.
  Útil si tienes varias conversaciones con fotos parecidas.
- **Rework del layout home**: la barra inferior de stats se separó
  visualmente del área de grabación; menos choque cromático con el
  círculo primario.
- **Ajustes premium**: `ListItem` con iconos por sección, agrupados
  en cards, sustituyen la lista plana anterior.

## 🔍 Changed

- `StatsScreen` corrige contadores que mezclaban conversaciones
  eliminadas — las métricas solo cuentan chats que siguen
  activos.

## Install

Actualización desde 1.3.1. Este es el último release del ciclo
1.3.x antes del roadmap de 16 items que arranca en 1.4.0.
