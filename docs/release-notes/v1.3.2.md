# v1.3.2 — Pre-roadmap polish 🧹

## 🐛 Fixed

- **Startup crash** in `Application.attachBaseContext`: the locale
  code path tried to read `applicationContext` before it was
  available, crashing with NPE on some cold starts. Moved the
  locale bootstrap to after `super.onCreate()`.

## ✨ Added

- **Tap-to-zoom photo** in Manage Pinned: tap a circle's round
  photo and you see it full-screen with pinch-to-zoom. Useful if
  you have several conversations with similar photos.
- **Home layout rework**: the bottom stats bar is now visually
  separated from the recording area; less chromatic clash with
  the primary circle.
- **Premium settings**: `ListItem` with per-section icons,
  grouped in cards, replace the old flat list.

## 🔍 Changed

- `StatsScreen` fixes counters that mixed in deleted
  conversations — metrics now only count chats that are still
  active.

## Install

Update from 1.3.1. This is the last release of the 1.3.x cycle
before the 16-item roadmap that starts in 1.4.0.
