# v1.17.3 — Android Auto home screen matches the phone aesthetic 🚗✨

The previous Auto home screen was utilitarian to the point of ugly:
a generic mic icon for Record plus three identical speech-bubble
tiles for text quick replies, with no visual connection to the
phone UI. v1.17.3 rebuilds the home screen to look like a car-safe
version of what the user sees on the phone.

## ✨ Changed — AA home screen

- **Pinned conversations render as circular avatar tiles** using
  each conversation's real photo (`photoLocalPath`), cropped to a
  circle at 192 px. Order matches the phone home: primary first,
  then secondaries by `sortOrder`. Tap any tile → start recording
  to that target (same pipeline as the phone's press-and-hold).
  Fallback when no photo is set: a tinted person silhouette.
- **Quick-reply shortcuts get kind-aware icons** matching the
  phone chips:
  - **Text shortcuts** → Bolt icon (new `ic_bolt.xml`).
  - **Voice shortcuts** → Mic icon + blue tint. Tap sends the
    pre-recorded `.ogg` to the primary (via `sendVoiceShortcut`
    — same path as v1.17.0 on the phone).
- **Pending-count tile** kept at the end of the grid for
  at-a-glance unread awareness.

## 🏗 Architecture notes

- `MainScreen` now takes `ConversationRepository` via the Hilt
  car-session entry point. It subscribes to `observePinned()` so
  the car screen updates live when the user reorders / adds
  pinned circles on the phone.
- `circleAvatarIcon(conv)` decodes the photo file off the Main
  thread (inside a `BitmapFactory.decodeFile` wrapped in
  `runCatching`), masks it to a centered circle via
  `PorterDuffXfermode(SRC_IN)`, and wraps the result in
  `IconCompat.createWithBitmap`. Falls back silently to a
  tinted person silhouette when the file is missing.
- The AA host limits grid tiles (typically 6–8 items). When the
  user has more pinned circles + shortcuts than that budget,
  **pinned conversations win** — the car context is
  conversation-first; shortcuts are phone-first.

## Install

Update from 1.17.2. Open Android Auto, tap the Autogram tile —
the home should now show the primary conversation's photo as a
round avatar (if configured) alongside any pinned secondaries
and properly-iconed quick-reply shortcuts.
