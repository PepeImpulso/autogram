# v1.23.0-rc.1 — Android default-assistant role (Phase 1 + Phase 2 testing)

Pre-release for on-device testing of issue #63: the Autogram assistant.
Built on top of v1.22.0 (cross-conv History/Pending + recording-vs-playback
fix). Stable users on v1.22.0 are not affected.

## What's new vs v1.22.0

- **AssistantActivity registered for `ACTION_ASSIST`** (Phase 1). Autogram
  should now appear in Samsung's Settings → Apps → Default apps →
  Digital assistant alongside Google / Bixby / ChatGPT / Claude.
- **Voice loop wired to Telegram MTProto + Merlín persona** (Phase 2).
  Long-press home (or whichever assistant gesture is active) opens the
  AssistantActivity. Tap the mic → speak → tap to send. The recording
  goes to your configured primary target (Merlín). The reply lands via
  the existing `MtprotoReceiverService` and plays through autoplay.
- State machine: `Idle → Listening → Sending → WaitingForReply →
  Replied | Failed`. 60s reply timeout. AssistantActivity auto-closes
  on `Replied`; backing out mid-turn still lets the reply arrive +
  play through Autogram's normal incoming-message path (graceful
  degradation).

## What to verify on the Galaxy

1. **Picker registration.** Open Settings → Apps → Default apps →
   Digital assistant. Autogram should be in the list.
2. **Activation.** Pick Autogram, trigger the assistant gesture (long-
   press home / side button — depends on your phone setup). The
   AssistantActivity should open.
3. **Voice loop.** Tap mic, speak a question to Merlín, tap stop.
   Verify the recording sends to your primary target and the reply
   plays through autoplay.
4. **Recording-vs-playback collision** (carries over from v1.22.0):
   while recording, an incoming message should NOT start playing.

## If Autogram does NOT appear in the picker

Samsung One UI may require a full `VoiceInteractionService`
implementation. Open issue #63 with a comment + One UI version and we'll
add Phase 1b. The voice loop in this build can still be tested by
launching `AssistantActivity` directly via adb:

```
adb shell am start -n com.autogram.app/.ui.assistant.AssistantActivity
```

In-app updater detects this pre-release; tap "Buscar actualizaciones"
in Ajustes to pull immediately. The CI auto-marks `-rc` tags as
GitHub pre-releases so users with auto-update on stay on v1.22.0
unless they opt in.
