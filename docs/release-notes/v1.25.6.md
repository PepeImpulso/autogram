# v1.25.6 — Resilient text-to-speech 🔁

This release recovers from transient Android text-to-speech service failures
instead of silently losing an incoming reply.

## 🐛 Fixed

- **Rejected TTS requests are retried safely.** When Android refuses to queue
  speech, Autogram rebuilds the engine and retries once with fresh utterance
  identifiers so callbacks from the discarded engine cannot corrupt playback.
- **Unheard text remains pending.** If the rebuilt engine also fails, the
  message returns to the durable playback queue instead of being marked failed
  and deleted.
- **TTS services remain discoverable.** The Android 11+ package-visibility
  declaration now includes installed text-to-speech engines.

## 🧪 Tests

- **Recovery behavior has regression coverage.** Tests verify the single-retry
  limit and that a repeated TTS rejection preserves the message in pending
  playback.
- **Both distributions verified.** The GitHub and Google Play unit-test suites
  and Android lint tasks pass.

## Install

Update through Autogram's in-app updater; no configuration changes are needed.
