# v1.12.0 — Rediseño premium de Atajos & Target Picker + fixes de resumen 🎨

## ✨ Rediseño — acabado premium

**ManagePinnedActivity (Atajos)** estaba apretado: cinco IconButtons
apelotonados junto al `ListItem` comprimían el título a una palabra
por línea ("Merli/nBot/Grou/p/ > CSO/Sales") y el FAB tapaba la
última fila. Reemplazado con `ElevatedCard` por círculo:

- Avatar 56dp con badge estrella primario en esquina inferior derecha.
- Título `titleMedium` + `maxLines=1` + ellipsis — lecturable aun
  con nombres largos.
- Chip de rol (Principal / Atajo) bajo el subtítulo, tintado con
  `primaryContainer` cuando activo.
- Reorder ↑/↓ como par vertical compacto — solo secundarios, y
  deshabilitados en los extremos.
- Acciones poco frecuentes (fijar como principal, set/clear foto,
  eliminar) colapsadas en un menú overflow.
- Spacer 72dp al final para que el último card no choque con el FAB.
- Fondo `surfaceContainerLow` para profundidad tonal.

**TargetPickerActivity** era una lista plana. Ahora:

- Campo de búsqueda con `Search` leading + clear ✕ trailing,
  debounced, resetea entre paso chat/topic.
- `ElevatedCard` por chat con icono según tipo en círculo
  `primaryContainer` (Person para DMs, Groups, Forum), título + label
  de tipo, chevron trailing.
- Paso Topic espeja el estilo con icono tag y tags general/closed
  como chips pequeños `surfaceVariant`.
- Estados loading/error/empty/no-match cada uno con su burbuja
  ilustrativa.
- Top bar de dos líneas: título + subtítulo contextual.

## 🐛 Fixed — resumen (bugs del usuario)

- **Audio original + resumen sonaban en paralelo** cuando el modo
  resumen estaba on. El receiver reproducía el `.ogg` *y* transcribía
  *y* resumía a la vez. Ahora `handleVoiceNote` comprueba settings:
  si resumen está on, **salta el audio original** y lee el mejor
  texto disponible (resumen > transcripción > textContent).
- **Resumen leído por voz inglesa en texto español.** Fix de dos
  capas:
  1. Prompts del LLM (Nano y endpoint) reforzados con "CRITICAL:
     write the summary in `<language name>`, translate if needed".
  2. `TtsPlayer.speak()` ahora acepta locale explícito, y
     `detectLocale()` inspecciona bloques Unicode (Hiragana/Katakana
     → ja, Hangul → ko, CJK → zh, marcadores español → es) para que
     un resumen en español siempre reciba voz española, aunque la UI
     esté en inglés.

## ✨ Added — botón "Reproducir original"

Pill outlined `tertiaryContainer` con icono de auriculares sobre el
círculo primario, visible cuando el target activo tiene una voz
entrante previa con audio todavía en disco. Tap → replay via
`playManually`. Deliberadamente con estilo distinto de los botones
tonal de quick-reply — para que se lea como acción secundaria.

## 🐛 Fixed — Sentry noise

`RuntimeException "stop failed"` del `MediaRecorder` cuando el
usuario suelta el botón demasiado rápido (<1.5s, empty frame) se
escalaba a Sentry como error. Ahora degradado a warning en ese
caso común — sigue propagando como error para fallos reales de
hardware/IO. Los ficheros vacíos se borran para que no se filtren
al outbox.
