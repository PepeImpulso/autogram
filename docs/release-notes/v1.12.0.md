# v1.12.0 — Premium redesign of Shortcuts & Target Picker + summary fixes 🎨

## ✨ Redesign — premium finish

**ManagePinnedActivity (Shortcuts)** was cramped: five
IconButtons crammed next to the `ListItem` squeezed the title
into one word per line ("Merli/nBot/Grou/p/ > CSO/Sales") and
the FAB covered the last row. Replaced with an `ElevatedCard`
per circle:

- 56dp avatar with a primary star badge on the bottom-right
  corner.
- `titleMedium` title + `maxLines=1` + ellipsis — readable even
  with long names.
- Role chip (Primary / Shortcut) below the subtitle, tinted
  with `primaryContainer` when active.
- Reorder ↑/↓ as a compact vertical pair — secondaries only,
  and disabled at the extremes.
- Infrequent actions (pin as primary, set/clear photo, delete)
  collapsed into an overflow menu.
- 72dp spacer at the end so the last card doesn't clash with
  the FAB.
- `surfaceContainerLow` background for tonal depth.

**TargetPickerActivity** was a flat list. Now:

- Search field with `Search` leading + clear ✕ trailing,
  debounced, resets between chat/topic step.
- `ElevatedCard` per chat with an icon per type in a
  `primaryContainer` circle (Person for DMs, Groups, Forum),
  title + type label, trailing chevron.
- Topic step mirrors the style with a tag icon and
  general/closed tags as small `surfaceVariant` chips.
- Loading/error/empty/no-match states each with their
  illustrative bubble.
- Two-line top bar: title + contextual subtitle.

## 🐛 Fixed — summary (user-reported bugs)

- **Original audio + summary played in parallel** when summary
  mode was on. The receiver played the `.ogg` *and* transcribed
  *and* summarized at the same time. Now `handleVoiceNote`
  checks settings: if summary is on, **skips the original
  audio** and reads the best text available (summary >
  transcription > textContent).
- **Summary read with an English voice over Spanish text.**
  Two-layer fix:
  1. LLM prompts (Nano and endpoint) reinforced with "CRITICAL:
     write the summary in `<language name>`, translate if
     needed".
  2. `TtsPlayer.speak()` now accepts an explicit locale, and
     `detectLocale()` inspects Unicode blocks
     (Hiragana/Katakana → ja, Hangul → ko, CJK → zh, Spanish
     markers → es) so a Spanish summary always gets a Spanish
     voice, even if the UI is in English.

## ✨ Added — "Play original" button

Outlined `tertiaryContainer` pill with headphones icon above
the primary circle, visible when the active target has a
previous incoming voice with audio still on disk. Tap → replay
via `playManually`. Deliberately styled differently from the
tonal quick-reply buttons — so it reads as a secondary action.

## 🐛 Fixed — Sentry noise

`RuntimeException "stop failed"` from `MediaRecorder` when the
user releases the button too quickly (<1.5s, empty frame) was
being escalated to Sentry as an error. Now downgraded to
warning in that common case — still propagates as an error for
real hardware/IO failures. Empty files are deleted so they
don't leak into the outbox.
