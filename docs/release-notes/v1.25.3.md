# v1.25.3 — Compact long-text shortcut editor 📝

This maintenance release keeps every shortcut editor control accessible when
the message contains a long prompt.

## 🐛 Fixed

- **Long messages no longer hide the destination picker.** The message field
  previously expanded to display its entire contents, pushing the “Send to”
  selector outside the useful dialog area. It now has a bounded height and
  scrolls internally after seven lines.
- **Save and cancel remain accessible.** The compact message editor preserves
  room for the destination selector and dialog actions across long prompts and
  smaller phone screens.

## 🧪 Tests

- **Regression verification.** The complete GitHub unit-test suite and Android
  lint pass with the constrained editor layout.

## Install

Update through Autogram's in-app updater, then edit a long text shortcut and
scroll inside the message field.
