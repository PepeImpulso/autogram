# v1.24.3 — Unified diagnostics + one-tap bug report 🧩📨

Consolidates the diagnostic surfaces that had been growing in the
Settings screen (AA-routing diagnostic row, v1.24.2's Debug logs card,
and the legacy "Send test event to Sentry" affordance). Single
Diagnostics section now hosts everything, and "Send bug report" packs
the log file into the Sentry event automatically so reporting an
in-car issue takes one tap.

## ✨ Added

- **Settings → Diagnostics → "Send bug report".** Primary CTA in the
  Diagnostics card. Tap it and the app:
  1. Materialises the rolling debug log (everything Timber has logged
     since the last clear).
  2. Attaches the log file to a Sentry scope.
  3. Captures an INFO-level event tagged `manual_report=true` so the
     developer can spot it amid auto-captured crashes.
  No separate share intent, no SAF, no copy-paste — you tap once and
  the full runtime trace lands in the issue tracker. When Sentry isn't
  configured (dev builds without the DSN), the row falls back to the
  system share sheet with the same log file attached.

## 🔍 Changed

- **Three diagnostic surfaces collapsed into one card.** The
  Diagnostics section now contains, in order:
  1. **Last playback route** — moved here from the "Android Auto
     routing" card (where it was awkwardly mixed with user settings).
  2. **Send bug report** — primary action (above).
  3. **Share log file** + **Clear logs** — manual fallback + clean-
     slate for a focused reproduction.
  4. **Developer mode** toggle.
  The "Android Auto routing" card now only hosts the user-tweakable
  settings (audio focus mode picker, TTS-as-nav toggle, Test playback
  button) — no diagnostic info mixed in.

## 🔍 Removed

- The standalone "Debug logs" card v1.24.2 introduced. Its two
  buttons (Share / Clear) live inside the unified Diagnostics card
  now. Same code under the hood (`FileLoggingTree`).
- The "Send test event to Sentry" row. Superseded by "Send bug
  report", which does the same Sentry plumbing plus the log
  attachment.

## 🛠️ Internal

- Sentry attachment built via `Sentry.withScope { scope ->
  scope.addAttachment(io.sentry.Attachment(path, "autogram.log",
  "text/plain")); Sentry.captureMessage(...) }`. Sets `manual_report`
  and `app_version` tags so the dashboard filter "tag:manual_report"
  surfaces user-initiated reports.
- Old `SentryTestRow` composable deleted. `BugReportRow` replaces it.
