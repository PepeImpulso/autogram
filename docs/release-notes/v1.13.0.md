# v1.13.0 — Carpetas de atajos 📁

**Cierre del roadmap de 16 items.** Cuando acumulas muchos círculos
fijados, las carpetas los agrupan en pestañas en la pantalla
principal para que el grid siga siendo escaneable.

## 🗄 Schema

- Nueva tabla `circle_folders(id, name, color, sortOrder)`.
- `ConversationEntity.folderId: String?` — referencia nullable (sin
  FK) (null = "sin carpeta", aparece bajo "Todas" pero nunca se
  filtra en una pestaña específica).
- Migración **v12→v13** crea la tabla y añade la columna de forma
  no destructiva, así que los usuarios existentes encuentran sus
  círculos exactamente donde estaban.

## 🧩 Domain / repo

- `CircleFolder` data class + `CircleFolderRepository` bound via
  Hilt.
- `ConversationRepository.setFolder(id, folderId)` + query DAO.
- **Borrado de carpeta** hace `conversations.folderId = NULL` primero
  — atómico, los miembros sobreviven y caen a "Todas".

## ✨ ManagePinned UI

- Nueva card "Carpetas" arriba de la lista con chip row horizontal:
  un chip por carpeta + un "Nueva carpeta" outlined al final. Tap →
  `AlertDialog` con `OutlinedTextField` para el nombre. Long-press
  sobre un chip existente → diálogo de confirmación que explicita
  el comportamiento no destructivo en el copy.
- Menú overflow de cada círculo gana sub-sección de carpeta:
  entradas tipo radio para "Sin carpeta" + cada carpeta
  configurada, con la actual marcada con estrella `primary`.

## ✨ MainActivity

- **`FolderTabRow`** sobre el círculo primario, visible solo si hay
  al menos una carpeta creada. `LazyRow` de `FilterChip`s, primer
  item siempre "Todas" (`selectedFolderId = null`). El círculo
  primario se mantiene visible en todas las pestañas; solo se
  filtran los secundarios.
- `MainViewModel` expone `folders` + `selectedFolderId` como
  StateFlow, así la pestaña seleccionada sobrevive a los round-trips
  por la bottom nav.

## Install

Actualización desde 1.12.x. Strings localizados a los 6 idiomas.
Los usuarios sin carpetas no ven la UI nueva — aparece solo al
crear la primera.
