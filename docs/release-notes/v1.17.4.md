# v1.17.4 — Android Auto tiles match the phone's premium aesthetic 🚗✨

The AA home screen in v1.17.3 rendered real conversation photos but the
tiles still looked generic compared to the phone: no gold ring, no mic
badge, shortcut chips were small tinted icons instead of the bold chip
pills the phone shows. v1.17.4 rebuilds every tile as a composited
384×384 bitmap so the car screen reads as "the same app, in landscape".

## ✨ Changed — AA tile rendering

- **Avatar tiles (primary + pinned secondaries).** Each tile now
  composites three layers:
  1. Circle-cropped photo, scaled from `conv.photoLocalPath` (falls
     back to a white person silhouette on a muted slate background
     when no photo is set).
  2. **Gold ring** (2.5% stroke, `#D4A44C`) wrapping the photo — same
     gold as the phone's `RecordCircle`.
  3. **Peach mic badge** (`#FFA66A` filled disc, white outline) at
     bottom-right with a white `ic_mic` glyph, matching the phone's
     "tap to record" affordance.
- **Shortcut tiles** now render as chip-style bitmaps: dark-brown
  rounded-rectangle background (`#3D2F26`, the phone's tonal chip
  container in dark theme) with the Bolt icon (text shortcuts, tinted
  gold) or Mic icon (voice shortcuts, tinted peach) centered inside.
  The chip is inscribed inside the tile's circular slot so AA's image
  masking doesn't clip the corners.
- `GridTemplate.setItemImageShape(ITEM_IMAGE_SHAPE_CIRCLE)` so AA
  draws every tile in a circle natively, eliminating the old square
  edge artifacts around the photos.

## 🏗 Architecture notes

- **CarIcon cache.** Re-rendering 7–10 bitmaps per `invalidate()`
  would waste cycles during state transitions. Each rendered
  `CarIcon` is now cached on `MainScreen` keyed by a stable identity:
  avatars key on `(conv.id + photoLocalPath + file.lastModified)` so
  the cache auto-invalidates when the user sets a new photo; shortcuts
  key on `(qr.id + kind)`. The cache is cleared on the Screen's
  `onDestroy` lifecycle callback.
- **Drawable → bitmap compositing.** Vector drawables (`ic_mic`,
  `ic_bolt`, `ic_person`) are rasterized through a throwaway bitmap
  with `setTint + setBounds + draw`, then drawn onto the main canvas
  centered. This guarantees antialiasing across API levels and lets
  the tint colour vary per call (gold vs peach on the same Bolt/Mic).
- All color constants (`COLOR_GOLD_RING`, `COLOR_PEACH_BADGE`,
  `COLOR_CHIP_BG`, `COLOR_SILHOUETTE_BG`) live in the
  `MainScreen` companion so the phone theme and the AA tiles can
  diverge cleanly without re-reading the Compose Color palette.

## Install

Update from 1.17.3. No schema changes. Open Android Auto, tap the
Autogram tile — the grid should now show gold-ringed circular
avatars with peach mic badges for each pinned conversation, and
brown chip-style tiles for text/voice shortcuts.
