# v1.9.0 — Contextual quick-reply suggestions 💡

Item #5 of the 16-item roadmap. Now that v1.8.x transcribes
incoming voice notes, we suggest 2-3 quick replies based on
the content. **Deterministic, no LLM, no network.**

## ✨ Added

- **`SuggestQuickReplyUseCase`** — pure function, ES + EN regex
  rules: location, arrival, call, thanks, greeting,
  how-are-you, when, can-you, yes/no. The language follows the
  incoming message: if Merlin writes to you in Spanish, the
  chips come out in Spanish even if your UI is in English.
- **Contextual chips in MainActivity**: horizontal `LazyRow` of
  `AssistChip`s above the primary circle, with × to dismiss
  manually. Tapping a chip = same path as your configured
  quick-reply.
- `MainViewModel` observes the active conversation's message
  stream and recomputes when a new one arrives. Chips clear on
  send and expire after 5 min.

## Design decision

The rule set is deliberately small. Too many patterns produce
irrelevant suggestions that the user starts ignoring — worse
than showing nothing. New rules only get in when I have a real
example that would have fired a useful chip.

## Install

Update from 1.8.x. Try it: ask Merlin "where are you?" and
you'll see "At home" / "On my way" appear as chips.
