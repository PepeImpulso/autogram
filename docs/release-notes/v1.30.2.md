# v1.30.2 — Resume where it paused, controls back on top ⏯️

Pause and resume now continue the message instead of starting it again,
and the playback buttons are back in the Home header.

## 🐛 Fixed

- **Resume restarted messages read aloud.** Android's text-to-speech has no
  real pause, so pausing a text message (or a transcription or summary)
  stopped it and Resume read it again from the beginning. Autogram now
  tracks the word being spoken and Resume continues from that word, on the
  phone and from the car's Pause / Resume tile. Voice messages already
  resumed from the paused position.

## 🔍 Changed

- **Pause / resume and Next are back in the header.** They sit to the
  right of the pending pill, next to the stop button, so the pill coming
  or going doesn't move them. The bottom "now playing" bar is gone.
- **Version moved under the app name** to make room for the buttons.
- **Pending pill is shorter while the playback buttons show.** It keeps
  the count with a queue icon instead of a second ▶ next to Resume.

## Install

Update through Autogram's in-app updater.
