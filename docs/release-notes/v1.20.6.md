# v1.20.6 — Android Auto messaging and USB audio recovery

This release switches Autogram back to Android Auto's official communication
surface and backs out the USB routing change that could mute playback while
Android Auto was connected.

## Fixed

- **Android Auto launcher visibility** now uses the documented templated
  messaging path: `MESSAGING` category, `minCarApiLevel=7`, and both
  `template` + `notification` capabilities.
- **Car conversation screen** now renders pinned conversations as
  `ConversationItem` rows with recent message history, voice recording action,
  and Android Auto text reply support.
- **USB Android Auto audio** no longer forces `setPreferredDevice()` to
  BUS/USB/HDMI car sinks. When a projected car output is detected, Autogram
  leaves routing to Android and plays voice replies with `USAGE_MEDIA`, matching
  the older versions that worked in the car.
