# Autogram v1.24.10

## Fixed

- Hardened the in-app updater so APK downloads are monitored after they are handed to Android DownloadManager.
- Added progress/status feedback for queued, paused, running, failed, and stalled update downloads instead of leaving Settings stuck on "Downloading update".
- Clarified the update dialog action as "Download and install".
- Improved the offline outbox banner so queued messages show "waiting for connection" while offline and "sending queued" after connectivity returns.

## Notes

- This release addresses Autogram issues #19 and #20.
