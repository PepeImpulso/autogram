# v1.19.8 — Top-right play/stop button mirrors any playback 🎧

Post-ship polish of the v1.19.7 top-right toggle. The button's
icon and click behaviour now match **whatever the user is
actually hearing**, not just the last original.

## 🔍 Changed

### Toggle mirrors any playback, not just the last original

v1.19.7 made the top-right button show Stop **only when the
last original was the thing playing**. If a queued reply, TTS
summary, or any other message was mid-playback the button
still showed Play — confusing, since "play" while already
playing doesn't mean anything intuitive. The underlying
toggle also replaced that playback with the last original on
tap rather than simply stopping it, which isn't what the
user's literal request asked for ("pressing it while playing
should stop").

Now:

- Any playback in flight (`Playing` or `Paused`, regardless of
  which message) → button shows **Stop**. Tap calls
  `stopAll()` and returns to silence.
- No playback → button shows **Play**. Tap starts the most
  recent incoming voice on the active target.
- Nothing to play AND nothing playing → button disabled.

Implementation: `MainViewModel.toggleLastOriginal()` now
checks `playbackStatus.value is Playing || Paused` before
deciding whether to stop or start. The HeroHeader composable
passes `isAnyPlaying` instead of the old `isPlayingLast` flag.

## Install

Update from 1.19.7. Same UI position, just a more honest icon
state.
