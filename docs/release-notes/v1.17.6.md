# v1.17.6 — AA tile sizes actually visible + higher resolution 🚗🔍

v1.17.5 made "some" changes but the user's DHU screenshot proved
that Merlin still looked the same size as the secondaries and the
shortcut chips were tiny brown squares floating in empty tile
space. The 76% vs 96% fill ratio wasn't dramatic enough to survive
AA's aggressive tile downsampling. v1.17.6 goes unmistakably
bigger.

## ✨ Changed — dramatic size difference

- **Primary circle fills 100% of the canvas** (was 96%). Photo
  fills the whole tile, gold ring sits flush against the edge.
- **Secondary circles shrink to 55% fill** (was 76%). Now
  visibly ~half the diameter of the primary. The 2× ratio maps
  the phone home's 176dp primary vs 88dp secondary.
- **Primary gold ring thicker**: 10% of radius (was 8%).
  **Primary mic badge bigger**: 40% of circle radius (was 32%).
  Combined with the bigger primary circle, the badge is now ~3×
  its v1.17.5 on-screen size.
- **Secondary ring / badge** sized 9% / 32% respectively (scaled
  slightly down from primary so the visual hierarchy stays).

## ✨ Changed — shortcut chips finally look like chips

- **Chip fills 94% of canvas** (was 76%). Previously the chip
  was a small dark square floating in empty tile space; now it
  actually looks like a button that takes up the tile.
- **Icon inside the chip 60% of chip size** (was 50%). Bolt or
  Mic glyph is now clearly visible at DHU / car screen scale.
- **Corner radius bumped to 16% of canvas** (was 8%) — slightly
  rounder chips match the phone's pill feel better.

## ✨ Changed — source bitmap resolution

- **Bitmap canvas 512 → 768 pixels**. Target: 2024 Seat Ateca
  MIB3 9.2" @ 1280×640 → AA tiles ~280-320px at `ITEM_SIZE_LARGE`
  → 768px source gives ~2.5× oversampling for crisp downscale.
- Memory cost: 768×768×4B ≈ 2.3MB per bitmap × ~10 cached tiles
  ≈ 23MB. Fine for a single-screen app.
- Icons inside the bitmaps (`ic_mic`, `ic_bolt`, `ic_person`)
  are rasterized at the full target pixel size per tile, so the
  extra canvas resolution translates to sharper icon edges too.

## Install

Update from 1.17.5. Open Android Auto, tap Autogram — Merlin
should now be visibly about twice the diameter of the CSO / CFO
tiles, shortcut chips should fill their tiles as bold brown
pills with prominent gold (text) or peach (voice) icons, and
everything should be sharper on the DHU preview and sharper
still on the real Ateca head unit.
