# v1.16.0 — Deep audit + hardening + full docs 🔍📋

Close of the post-roadmap sprint. Three audit passes (testing
coverage, bug re-audit, third pass focused on
security/i18n/accessibility) + retroactive documentation of
the 25 previous releases.

## 🐛 Fixed (critical/high)

- **`Long → Int` overflow in `PinnedPickerViewModel`**: the
  `.toInt()` cast of a 64-bit `forumTopicId` could truncate
  without warning on chats with high IDs. Replaced with an
  `asInt32OrNull()` helper, which logs + returns null if it
  doesn't fit. 2 sites fixed.
- **`state.error!!` in two pickers** (TargetPicker,
  PinnedPicker): when `error` was null but the flow hit the
  error branch, it crashed with NPE. Changed to `state.error
  ?: stringResource(...)`.
- **`scrubPii` regex ate trailing whitespace and matched pure
  digit IDs**: order fix (LONG_ID first) + stricter pattern
  (phone requires `+` prefix or separator groups). 11 MockK
  tests that surfaced the bugs.
- **WorkManager crash in unit tests**:
  `RetryWorker.enqueueOnce()` assumed WorkManager was
  initialized; wrapped in `runCatching` with a `Timber.w`
  fallback, non-fatal because the worker has its own schedule.

## 🐛 Fixed (medium)

- **Hardcoded Spanish activity labels** in the
  `AndroidManifest` (`ManagePinnedActivity`,
  `PinnedPickerActivity`, `QuickRepliesSettingsActivity`).
  Replaced with strings.xml references — now translated into
  the 6 languages like the rest of the UI.
- **Backup size limit on import**: a hostile `.autogram`
  >100 MB could OOM the import (plaintext + BackupPayload +
  base64 simultaneously on the heap). Now rejects files
  >50 MB as `Corrupt` before attempting to decrypt.
- **LLM endpoint validation**: `Request.Builder().url()` with
  a malformed URL threw `IllegalArgumentException` and
  crashed the summarize/suggest path. Now scheme (`http`/
  `https`) is validated and parsed with `toHttpUrlOrNull()`
  first — silent failure to "NotAvailable" / regex fallback.
- **Auto-clear of `selectedFolderId`**: when the user
  deleted the active folder, the tab filter was left
  pointing at a nonexistent ID → the grid appeared empty
  even though there were circles. Now detected and cleared
  to "All" automatically.
- **`CircleFolderDao.detachAndDelete`** promoted to
  `@Transaction` so "clear folderId on conversations +
  delete folder" is atomic — before, a crash between the two
  left conversations pointing at a deleted folder.

## 🧪 Tests — 61 new

- 33 coverage tests: `PlayReplyUseCase` (18 tests for gates +
  state transitions), `OutboxRetryUseCase` (10 tests),
  `RetryWorker → OutboxRetryUseCase` refactor so it can be
  tested without WorkManager.
- 11 `AutogramApplicationScrubTest` tests (Sentry PII
  scrubber).
- 10 `SendVoiceMtprotoUseCaseTest` tests (happy path, offline
  queue, auth-not-ready, no-target, TDLib error, preview
  cancel).
- Round-trip backup test `ExportImportUseCase.export →
  import` ensuring 600k iters are actually applied.

**Totals: 61 new tests, 0 failures.**

## 🔧 Internal

- **`publish_autogram_release.sh` script updated** to
  auto-detect `docs/release-notes/v<tag>.md` and apply it as
  the release body. Also accepts an explicit `--notes <file>`.
- **Retroactive documentation** of the 25 previous releases
  (v1.2.3 → v1.15.0) in NitrOdoo format, applied via
  `gh release edit`. Any user can now read the "what
  changed" of any historical version from the GitHub UI.
