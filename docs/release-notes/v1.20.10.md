# v1.20.10 — AA templated messaging, phone-side audio, un-cropped icon

Three fixes on top of the 1.20.9 brand refresh. The Android Auto screen
now actually shows the user's conversations (instead of Gearhead's stock
empty inbox), tapping the headphones icon while USB-AA is connected
plays the message out loud through the phone, and the launcher icon is
no longer clipped by circular launcher masks.

## Fixed

- **Android Auto no longer shows "No messages received while driving".**
  `automotive_app_desc.xml` used to declare both `<uses name="template" />`
  and `<uses name="notification" />`. Gearhead 16.5 interprets that
  combination as a notification-sourced messaging app, so tapping the
  Autogram tile in the car opened Gearhead's built-in inbox (always
  empty for us, since we don't post persistent notifications for every
  received message) instead of our templated CarAppService. Dropping
  `notification` forces Gearhead to launch our ListTemplate with the
  pinned conversations + their recent messages populated. The
  `CarAppExtender` we still attach to each incoming-message notification
  keeps the in-car heads-up banner working.
- **Phone-side playback works while USB-AA is connected.** `AudioPlayer`
  used to yield to OS-default routing whenever a projected car sink
  (BUS / USB / HDMI) was present, which in an active AA session silently
  routed our MediaPlayer into the car session — audio vanished. It now
  explicitly picks the phone's own output (Bluetooth A2DP → wired
  headset → built-in speaker, in that order) so tapping the headphones
  icon on the phone always produces audible output from the phone or
  paired personal headphones.
- **Launcher icon no longer gets its corners clipped.** The v1.20.9
  adaptive foreground filled the full 432×432 canvas, so Pixel-style
  circle masks and Samsung-style squircles cut into the rounded
  square's corners. The foreground is now scaled to ~72% of the canvas
  and centered, so the full rounded-square icon stays visible under any
  launcher mask. The surrounding area blends into the solid brand-brown
  adaptive background.

## Install

Update from Autogram's in-app updater. No schema change, no new
permissions. The launcher may take a cache cycle to refresh the new
icon; long-press and re-drag from the app drawer if the old version
lingers.
