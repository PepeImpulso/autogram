# v1.26.0 — Open source, safer updates, tap-to-record in the car 🔓

Autogram is now open source under GPL-3.0. This release hardens the in-app
updater before the code went public, brings phone-style tap-to-record to the
Android Auto screen, and keeps more personal data out of crash reports.

## ✨ Added

- **Tap-to-record in the car.** The Android Auto home screen now shows a grid
  of contact tiles like the phone: tap a contact to start recording, tap it
  again to send, without switching to a separate recording screen. A Cancel
  button appears in the toolbar while recording, because car screens have no
  long-press. Voice commands keep working.
- **Short spoken pointer for approval requests.** Long Hermes approval
  messages are announced with a short Telegram pointer instead of being read
  out in full.

## 🐛 Fixed

- **Updates are verified before installing.** The updater now checks that a
  downloaded APK matches the SHA-256 published by GitHub, has Autogram's
  package name, is signed with the same key as the installed app and has a
  newer version code. Previously any APK in the release was handed straight
  to the installer.
- **Updates only come from the official release repo.** Download links must
  point to `PepeImpulso/autogram-releases` over HTTPS, and only the exact
  `autogram-<version>.apk` asset is accepted.
- **No more test builds on stable installs.** Stable versions ignore
  pre-releases (alpha, beta, rc).

## 🔍 Changed

- **Crash reports carry less personal data.** Crash screenshots are off (they
  could show contact names and message text), log lines no longer include chat
  names, search queries, transcripts or file names, and shared bug-report logs
  mask phone numbers, ids, emails and @usernames.
- **Google Play build retired.** Autogram is distributed only through GitHub;
  the separate Play build and its review demo were removed.
- **Release APKs use signature scheme v3** (alongside v2) and each release
  ships a `.sha256` checksum file.

## Install

Update through Autogram's in-app updater (Settings → Updates). This is the
last update installed by the old updater; from here on every update is
verified before it opens the installer.
