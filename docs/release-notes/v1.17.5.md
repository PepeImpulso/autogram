# v1.17.5 — AA home optimised for Seat Ateca & premium car screens 🚗✨

Follow-up to v1.17.4. User screenshot from the DHU showed:
(a) the "Autogram" wordmark + logo ate ~60dp of vertical space for
zero value, (b) every secondary tile was labeled "MerlinBotGroup"
(the chat name) instead of the actual topic name, (c) shortcut tiles
("Mejora", "Correo", "Tiempo") were buried behind scroll because the
7 pinned conversations filled the grid first, (d) tiles looked
blurry because 384px bitmaps downscaled too aggressively for a
9.2" MIB3 screen. Fixed all of that.

## ✨ Changed — AA home layout

- **Header wordmark + logo removed.** `GridTemplate.setTitle(" ")`
  and no `setHeaderAction(Action.APP_ICON)`. The action strip
  (silent toggle + "Comando por voz") stays pinned to the top
  right. Reclaims ~60dp for bigger tiles.
- **`GridTemplate.setItemSize(ITEM_SIZE_LARGE)`** — largest tile
  size AA allows. Uniform across the grid (per-item sizes aren't
  permitted), but bigger everywhere.
- **Ordering now matches driver priority, not phone-home order**:
  1. Primary target (Merlin) — always first.
  2. Quick-reply shortcuts (Mejora / Correo / Tiempo / …) — one-tap
     sends while driving, so they win over the 7th pinned contact.
  3. Secondary pinned conversations — reachable by scroll when the
     grid budget overflows.
- **Tile titles use `topicName` when the conversation is a forum
  topic** (falls back to `targetTitle`). Fixes the "every
  secondary says MerlinBotGroup" bug — now they show "CSO — Sales",
  "CFO — Finance", etc., matching the phone.

## ✨ Changed — tile rendering

- **Merlin visually bigger than secondaries.** AA forces uniform
  tile containers, so we fake size difference inside the bitmap:
  Merlin's circle fills 96% of the canvas, secondaries fill 76%.
  Result: even though AA renders both tiles at the same physical
  size, Merlin's drawn content is ~35% larger, conveying primary
  priority.
- **Mic badge bigger and anchored to the circle edge** at 45°
  (bottom-right), sized at 32% of the circle radius for primary
  and 30% for secondaries. Previously the 11% badge was invisible
  on the DHU.
- **Source bitmaps bumped to 512×512** (from 384). Target: the
  **2024 Seat Ateca** running MIB3:
  - SE trim (8.25" screen, 800×480) → AA tiles ~150-180px →
    512px source gives ~3× downsampling headroom.
  - SE Technology and above (9.2" Discover Pro, 1280×640) → AA
    tiles ~280-320px → 512px source gives ~1.6× headroom — still
    sharp at LARGE tile size.
  - The DHU's 800×400 virtual display is *lower* resolution than
    either real car screen, so tiles will look noticeably crisper
    in the car than in the DHU preview.

## Install

Update from 1.17.4. No schema changes. Open Android Auto, tap the
Autogram tile — the home should now show Merlin as a visibly
larger circle with shortcuts next to it, secondaries smaller
below, and no "Autogram" header bar eating the top of the screen.
