# v1.20.20 — Per-circle badge clears on playback

A follow-up tweak now that auto-play actually plays again on v1.20.19.

## Changed

- **Per-circle pending badges decrement once the message is played.**
  Previously the red "N" badge over each circle on Home only cleared
  when the user did one of: (a) sent an outgoing reply, (b) opened
  History for that circle, (c) tapped the badge itself. Receiving and
  hearing a voice reply via auto-play left the badge stuck even
  though the user had clearly "dealt with" the message. The badge
  query now excludes rows in `MessageState.PLAYED`, so the count
  drops by one as each message finishes playing — whether it was
  auto-played, drained from the pending queue, or replayed manually
  from History. The "answered = lastRepliedAt advanced" path still
  works on top of this for users who want the badge to mean
  "outstanding reply".
