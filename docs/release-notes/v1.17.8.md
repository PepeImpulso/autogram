# v1.17.8 — Fix AA Badge crash 🩹

v1.17.7 introduced the native mic-badge overlay via AA's `Badge`
API but the builder was missing `setHasDot(true)`. AA's Badge
requires the dot to be explicitly enabled before you can set its
background colour — without it the builder throws
`IllegalStateException: The dot must be enabled to set the
background color.` and the whole Screen crashes on first render.

## 🐛 Fixed

- Added `.setHasDot(true)` to the `Badge.Builder` chain in
  `micBadge()`. With hasDot + backgroundColor + icon the host
  renders exactly the peach mic disc we want.
