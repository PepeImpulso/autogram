# v1.24.5 — Voice replies finally reach the car speakers 🔊🚗

Symmetric fix for Pepe's "text replies play in the car, voice replies
don't" report from the Seat Ateca. v1.24.0 gave TTS an escape hatch
(USAGE_ASSISTANCE_NAVIGATION_GUIDANCE — the same audio path Google Maps
directions use) for cars whose audio policy silently mutes USAGE_MEDIA
from a background app. The voice-message playback path was left on
USAGE_MEDIA, so the symptom split cleanly: text shortcut → TTS → nav
path → audible; voice shortcut → MediaPlayer → USAGE_MEDIA → silent.

## 🔧 Fixed

- **Voice message replies inaudible in Android Auto while text replies
  worked.** `AudioPlayer.buildPlaybackAttributes()` was hardcoded to
  `USAGE_MEDIA + CONTENT_TYPE_SPEECH` — the path AA's media arbiter
  silently mutes when Maps / the AA host hold focus. Meanwhile
  `TtsPlayer.speak()` already had a `ttsAsNavigationPrompt` branch that
  switched it to `USAGE_ASSISTANCE_NAVIGATION_GUIDANCE +
  CONTENT_TYPE_SONIFICATION` (the Maps directions path), which the car
  routes reliably to the speakers. v1.24.5 plumbs the same toggle into
  `AudioPlayer.play()` via a new `useNavigationUsage: Boolean`
  parameter, and `PlayReplyUseCase.playVoiceMessage` / `playManually`
  now pass `settings.ttsAsNavigationPrompt` to both engines. One
  user-facing switch, both engines covered.

## 🔍 Changed

- **Settings toggle relabelled.** What was "Speak text as navigation
  prompt" is now "Use navigation-prompt audio path", and the
  sub-text explicitly calls out that the switch covers BOTH TTS and
  incoming voice replies. Old behaviour for TTS is unchanged when
  the toggle is OFF; the new behaviour for voice playback is unchanged
  when the toggle is OFF (still USAGE_MEDIA). Flip the toggle ON if
  voice replies still don't reach the car after this update.
- **AA settings tab row label** changed from "TTS as nav prompt" to
  "Nav-prompt audio path" to match the phone Settings wording.

## 🧪 Build status

- `:app:assembleRelease` green.

## Install

In-app updater. Stable channel. If the previous default of "navigation
prompt: OFF" was working for your TTS replies, voice replies should
now also play through the same media stream by default — no action
needed. If voice replies are still silent in your car, toggle
"Use navigation-prompt audio path" ON in Settings → Android Auto.

## Migration notes

No schema change. The existing `ttsAsNavigationPrompt` column on
`settings` is reused for both engines; the only change is that the
flag now also controls `AudioPlayer`'s `AudioAttributes`.
