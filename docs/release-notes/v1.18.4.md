# v1.18.4 — Merlin really moves to the top-left now 📐

v1.18.3 only shifted Merlin up by ~9 pixels on a 700-pixel surface
— barely a rounding error. User's screenshot correctly flagged it
looked the same. Root cause: I'd reserved 14% of the surface
height as top padding "for the ActionStrip", but the ActionStrip
only occupies the top-right area; the left side is free all the
way to y=0.

## ✨ Changed

- **`topPadding` cut from 14% → 4% of surface height.** On the
  1190×700 DHU surface that moves the content origin up by
  ~70 px, which is ~10% of the visible height — an obvious
  jump, not a rounding error. `sidePadding` also trimmed a
  touch so Merlin hugs the left edge more tightly.
- **Primary label dropped.** The user's Merlin avatar already
  has "Merlín / CHIEF AI OFFICER" baked into the photo, and a
  duplicate external label was colliding with the secondary
  row below it (the "Merli" overlap visible in the v1.18.3
  screenshot). Secondaries still get labels because their
  topic names don't match the photo captions.

## Install

Update from 1.18.3. If the DHU still looks identical, force-stop
Android Auto on the phone once (Settings → Apps → Android Auto →
Force stop) so Gearhead discards any cached render state.
