# v1.25.9 — Clearer car playback 🚗

This release removes audio time stretching from downloaded voice messages
while a projected car connection is active, targeting robotic or distorted
Hermes replies on Samsung Android 16 devices.

## 🐛 Fixed

- **Voice messages play at their original speed in the car.** Autogram now
  bypasses `MediaPlayer` speed processing during Android Auto sessions because
  that OEM processing path can distort some OGG/Opus replies even though the
  same file sounds clear through the phone speaker.
- **Phone playback keeps the selected speed.** The car-specific safeguard does
  not alter the user's configured playback speed outside a car connection.

## 🧪 Tests

- **Car detection paths are covered.** Regression tests verify the 1x safeguard
  for both an active Android Auto connection and a projected output detected
  while the host connection state is stale.

## Install

Update through Autogram's in-app updater; no configuration changes are needed.
