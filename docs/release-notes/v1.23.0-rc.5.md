# v1.23.0-rc.5 — assistant pre-release rebased on v1.22.4 🎙️🤖

Catches the assistant feature branch up with everything that landed on
master since rc.4 was cut. No new assistant work in this rc — its
purpose is simply to deliver the v1.22.4 improvements (pulsing playback
ring + AA voice search + Bluetooth headset routing) to people who are
already running the rc.x assistant pre-release on their phone.

## ✨ From v1.22.4 (now also in this rc)

- **Home · Pulsing gold ring while playback is active.** The contact
  circle whose message is being read aloud gets an animated gold ring.
  Lets you identify the speaker at a glance — important when audio
  routes to the car speakers and the phone screen is glanceable rather
  than focused. Driven by a new
  `MainViewModel.currentlyPlayingConversationId` StateFlow.
- **AA / Assistant · Voice search support.** "Hey Google, play X on
  Autogram" now reaches the app via a new `MEDIA_PLAY_FROM_SEARCH`
  intent-filter + `onPlayFromSearch` callback override. Empty query
  drains pending; non-empty query is matched case-insensitively against
  pinned conversation titles.
- **Bluetooth headset · Hardware media-button routing.** Declared
  `MediaButtonReceiver` in the manifest so pause/play/skip from a paired
  Bluetooth headset (or wired-headset remote) routes to the active
  MediaSession while Autogram is speaking.

## 🤖 Assistant work (unchanged from rc.4)

- Phase 1 — manifest registration so Autogram appears in Settings →
  Default digital assistant app.
- Phase 1b — `VoiceInteractionService` chain so the long-press-home /
  side-key gesture actually binds Autogram (Samsung-specific path).
- Phase 2 — voice loop sending to the configured target (Merlín by
  default).
- Phase 5 starter — multi-contact target picker so the assistant can
  route the voice note to any pinned circle, not only the default.

## 🧪 Tests + verification

- `:app:assembleDebug`, `:app:testDebugUnitTest`, `:app:lintDebug`
  all green after merging master.
- v1.22.4's two new lint errors (`MissingIntentFilterForMediaSearch`,
  `MissingOnPlayFromSearch`) are cleared by the same fixes that
  landed in v1.22.4.
