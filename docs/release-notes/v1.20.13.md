# v1.20.13 — Lint fix for v1.20.12

v1.20.12 (the audit-fix follow-up to v1.20.11) failed CI at the lint
step: `settings_silent` and `settings_silent_sub` were removed from the
default and English/Spanish locales when the silent toggle was deleted,
but the German / French / Japanese / Chinese translations were left
behind. Lint's `ExtraTranslation` check refuses to ship strings that
exist only in non-default locales.

This release ships the same code as v1.20.12 plus the orphan-string
cleanup so the build actually publishes.

## Fixed

- **CI build error: ExtraTranslation for `settings_silent` /
  `settings_silent_sub`.** Removed the orphan strings from
  `values-{de,fr,ja,zh}/strings.xml`.

## Carried over from v1.20.12 (never reached users)

- `stopAll()` no longer clears the in-memory pending queue — it only
  stops the current playback. The queue is now durable user-facing
  data.
- `playAllPending` and `playFromHere` hard-stop in-flight playback
  before popping, so the first queued message can't be re-enqueued at
  the back of the queue (with its DAO row already deleted) when
  something else is playing.
- `IncomingMessageNotifier.reconfigureBadgeFor` remembers the desired
  badge value as a `@Volatile` field so notifications posting in the
  microsecond delete-recreate window of the channel can't clobber the
  user's preference.

Update from Autogram's in-app updater. v1.20.11 ships the new pending-
