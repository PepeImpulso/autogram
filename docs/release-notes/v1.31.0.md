# v1.31.0 — Play the last message from the car 🎧

The car screen now has the phone's headphones button: one tap plays the
last message you received.

## ✨ Added

- **"Play last message" on the car screen.** A compact row with the
  headphones icon sits under the contacts in the Grabar grid, the same
  size as the Pause and Next rows. Tapping it plays the most recent
  received message, like the headphones button on the phone's Home. While
  a message is playing the row gives way to Pause and Next, and it comes
  back when playback ends. It stays hidden until there is a message to
  play.

## Install

Update through Autogram's in-app updater.
