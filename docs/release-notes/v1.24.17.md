# v1.24.17 — Telegram reconnect from signed-out screen

Pepe found that the Telegram connection screen could get stuck on:

> Signed out. Reopen the app to connect again.

That state had no action, and on Android a simple reopen can keep the same
application process alive, so TDLib was never recreated.

## Fixed

- The TDLib wrapper now releases the in-memory client when TDLib reaches the
  terminal `AuthorizationStateClosed` state. Opening the login flow again can
  create a fresh TDLib client instead of staying stuck.
- The signed-out screen now offers two explicit actions:
  - **Reconnect** — starts TDLib again and continues the normal Telegram auth
    flow.
  - **Reconfigure connection** — clears Autogram's local TDLib auth database
    and encryption key, then starts Telegram setup from scratch.

## Update notes

Update from Autogram's in-app updater. No database schema change.
