# v1.25.2 — Stable shortcut reordering 🔀

This maintenance release fixes a crash that could close the Shortcuts editor
when rearranging items.

## 🐛 Fixed

- **Shortcut drag-and-drop no longer returns to Home.** The reorder callback
  exposed full list indices that included the fixed visibility card, while the
  app applied them directly to the shortcut-only collection. Dragging the last
  of six shortcuts therefore attempted to remove index 6 from a six-item list.
  Autogram now translates those indices correctly and safely handles transient
  footer targets during a drag.
- **Reordered shortcuts persist reliably.** A completed drag now reaches the
  existing repository update instead of being interrupted by the index crash.

## 🧪 Tests

- **Boundary regression coverage.** Tests cover the original six-item crash,
  first-to-last and last-to-first moves, footer targets, and invalid header
  sources. The full GitHub unit-test suite and Android lint pass.

## Install

Update through Autogram's in-app updater, then open Settings → Shortcuts and
drag an item using its handle.
