# v1.29.2 — Cleaner car record flow 🚗

The car test of v1.29.1 confirmed that sending now drops back to the Grabar
grid. This release polishes the rest of that flow.

## 🐛 Fixed

- **No red stop icon flashing on the grid.** When going back to the grid
  after sending, the contact's photo briefly showed the red stop badge. The
  badge is meant for recording on the grid itself (the experimental in-grid
  buttons), so it is now drawn only when those buttons are active.
- **One language in the car.** The car grid followed the phone's system
  language while the recording screen followed Autogram's own language
  setting, so the two could differ. Both now follow Autogram's language
  setting (Settings → Language).

## 🔍 Changed

- **The recording screen points to the big button.** Android Auto decides
  the size of the player buttons, so the small ➤ cannot be made bigger. The
  big ⏸ button already sends the message, and the text under the contact
  now says so: "Tap the big ⏸ button to send it".

## Install

Update through Autogram's in-app updater. If the car now shows a different
language than before, change it in Autogram's Settings → Language.
