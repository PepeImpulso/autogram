# v1.20.16 — History conversation switcher + FAB nudge

Two follow-ups on v1.20.15.

## Fixed

- **Developer-mode camera FAB no longer overlaps the Settings icon in
  the bottom nav.** The 96 dp bottom inset was enough to clear
  Material 3's nominal 80 dp NavigationBar but missed the system
  gesture bar on phones where the combined nav region exceeds 96 dp.
  Bumped to 140 dp so the FAB sits comfortably above any reasonable
  bottom-nav + gesture-bar stack.

## Added

- **Conversation switcher inside History.** The toolbar title is now
  tappable when more than one conversation is pinned (chevron icon
  hint). Tap it to open a dropdown of every pinned conversation; pick
  one and the message list switches without going back Home. Useful
  when you want to browse Niobe / Analyst / etc. histories without
  bouncing to the home screen and re-tapping each badge. The
  conversation chosen here also gets its `lastRepliedAt` bumped, so
  the per-circle pending badge for that conversation clears the moment
  you view it via the dropdown — same "view = ack" behaviour as the
  badge-tap entry path.

## Tests

## Install

Update from Autogram's in-app updater. No schema change. Once you're
on v1.20.16 you can finally browse every chat's history end-to-end
from the History screen alone.
