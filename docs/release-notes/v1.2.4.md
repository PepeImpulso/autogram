# v1.2.4 — Release ops runbook 📋

## 🔧 Internal

- Runbook `docs/RELEASE_OPS.md` con el proceso completo de
  release: cortar tag, firmar APK, subir al repo de releases,
  verificar el auto-updater.
- Scripts reutilizables en `scripts/`: `build_release_apk.sh`,
  `publish_autogram_release.sh` con firma local y `gh release
  create` parametrizable.

No hay cambios de comportamiento de la app — solo plumbing
interno para que cada release futuro sea un one-liner.
