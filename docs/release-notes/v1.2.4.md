# v1.2.4 — Release ops runbook 📋

## 🔧 Internal

- Runbook `docs/RELEASE_OPS.md` with the full release process:
  cut tag, sign APK, upload to the releases repo, verify the
  auto-updater.
- Reusable scripts in `scripts/`: `build_release_apk.sh`,
  `publish_autogram_release.sh` with local signing and a
  parameterizable `gh release create`.

No app behavior changes — just internal plumbing so every future
release is a one-liner.
