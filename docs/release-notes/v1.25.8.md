# v1.25.8 — Resilient voice playback 🚗

This release recovers voice-message playback from a Samsung Android 16 media
engine failure and carries the Google Play launch compatibility improvements
into the standalone build.

## 🐛 Fixed

- **MediaPlayer invalid operations recover once.** When an Android media engine
  reports error `-38`, Autogram replaces the failed player and retries at 1x
  with system-managed routing, avoiding a lost Telegram voice message without
  risking an infinite retry loop.
- **Onboarding actions remain reachable.** First-run buttons now stay above the
  system navigation area on edge-to-edge devices such as recent Samsung phones.
- **Android Auto declarations no longer conflict.** Autogram keeps projected
  Android Auto support without incorrectly claiming Android Automotive OS
  hardware, allowing the same source tree to satisfy Google Play validation.

## 🔧 Internal

- **Distribution identities are isolated.** Google Play uses
  `com.impulsotecnologico.autogram`, while the standalone updater keeps
  `com.autogram.app` so existing installations remain upgrade-compatible.

## 🧪 Tests

- **Recovery and distribution paths are covered.** Regression tests exercise
  the one-retry media policy, and both GitHub and Play variants build and pass
  their unit-test suites.

## Install

Update through Autogram's in-app updater; no configuration changes are needed.
