# v1.10.0 — Listen/Reply from notification + auto-update + badges toggle 🔔

Three user-requested features in one cut.

## ✨ Added

- **Listen / Reply actions on incoming-message notifications.**
  The MessagingStyle + CarAppExtender notification now exposes a
  **Listen** button (plays the audio or reads the text via TTS
  via `PlayReplyUseCase`) and a **Reply** button with
  `RemoteInput`. Reply sends the text through the same
  `sendQuickReply` you use from the app and dismisses the
  notification on success. Useful on Android Auto and wearables
  where opening the full app isn't practical.
  - New `NotificationActionReceiver` (`@AndroidEntryPoint`
    BroadcastReceiver, not exported). Uses `goAsync()` to get
    more than 10s of headroom for Room/TDLib.
- **Auto-update banner on the main screen.** The silent check
  every 6h and the `Available` dialog were already running; now
  we add **Downloading** and **Error** banners over the nav bar
  — visual feedback while the APK is downloading and a one-tap
  shortcut to Settings → Updates if it fails.

## 🔍 Changed

- **"N" pending-message badges are now opt-in.** Before, they
  only cleared on send, so they grew indefinitely for chats you
  don't feel obligated to reply to. New
  `settings.showPendingBadges` toggle (default OFF, migration
  v10→v11) in Settings → Playback. If you like visual pressure,
  you turn it on.

## Install

Update from 1.9.x. Strings localized into the 6 languages.
