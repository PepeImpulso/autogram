# v1.10.0 — Listen/Reply desde notificación + auto-update + toggle de badges 🔔

Tres features pedidas por el usuario en un corte.

## ✨ Added

- **Acciones Listen / Reply en las notificaciones de mensaje entrante.**
  La notificación MessagingStyle + CarAppExtender ahora expone un
  botón **Escuchar** (reproduce el audio o lee el texto por TTS via
  `PlayReplyUseCase`) y un botón **Responder** con `RemoteInput`.
  El Reply envía el texto por el mismo `sendQuickReply` que usas
  desde la app y descarta la notificación al tener éxito. Útil en
  Android Auto y wearables donde abrir la app entera no es práctico.
  - Nuevo `NotificationActionReceiver` (`@AndroidEntryPoint`
    BroadcastReceiver, no exported). Usa `goAsync()` para tener más
    de 10s de margen en Room/TDLib.
- **Banner de auto-actualización en pantalla principal.** Ya corría
  el check silencioso cada 6h y el diálogo para `Available`;
  ahora añadimos banners de **Descargando** y **Error** sobre la
  barra de navegación — feedback visual mientras baja la APK y un
  atajo de un toque a Ajustes → Actualizaciones si falla.

## 🔍 Changed

- **Los badges "N" de mensajes pendientes ahora son opt-in.** Antes
  solo se limpiaban al enviar una respuesta, así que crecían
  indefinidamente para chats que no te sientes obligado a contestar.
  Nuevo toggle `settings.showPendingBadges` (default OFF, migración
  v10→v11) en Ajustes → Reproducción. Si te gusta la presión visual,
  lo activas.

## Install

Actualización desde 1.9.x. Strings localizados a los 6 idiomas.
