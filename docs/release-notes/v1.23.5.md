# v1.23.5 — Tap-to-toggle voice recording

Small but important usability polish for recording messages from contact circles.

## ✨ Changed

- **Contact voice recording now works as a toggle.** Tap a contact circle once to start recording, then tap it again to stop and send. The user no longer needs to keep the button pressed while speaking.
- **Clear active recording state.** The active contact still gets the red recording treatment, but now shows a stop icon to make the second tap behavior explicit.
- **Long-press cancel escape hatch.** While a recording is active, long-pressing the active circle cancels the recording, preserving a quick way to discard a mistake.
- **Onboarding copy updated.** The recording step now explains tap-to-start / tap-to-stop instead of the old press-and-hold flow.
