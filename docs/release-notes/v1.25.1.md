# v1.25.1 — Reliable queue delivery and Android Auto audio 🔊

This maintenance release fixes messages that could remain queued after
connectivity returned and hardens playback routing for recent Android Auto beta
versions.

## 🐛 Fixed

- **Queued messages drain as soon as Telegram reconnects.** WorkManager could
  enter exponential backoff before TDLib finished authenticating, leaving the
  home screen stuck on “Sending queued” despite an active internet connection.
  Autogram now starts a serialized outbox drain when TDLib reaches its ready
  state, without risking duplicate delivery.
- **Android Auto beta audio routing.** Some recent Android Auto hosts expose the
  projected car audio device before updating their connection-state provider.
  Voice messages and text-to-speech now recognize that physical route as a car
  session and use the navigation-prompt audio path instead of an inaudible media
  channel.

## 🧪 Tests

- **Queue and routing regression coverage.** The GitHub distribution passes its
  unit-test suite and Android lint, including a new stale-host-state routing
  scenario.

## Install

Update through Autogram's in-app updater, then reconnect Android Auto before
testing queued delivery and incoming audio.
