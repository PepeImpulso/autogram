# v1.5.0 — Pulido UX (M2) ✨

Segundo milestone del roadmap: vibración con los pitidos, preview
antes de enviar, reordenar círculos, y bloqueo biométrico opcional.

## ✨ Added

- **Haptic feedback** (`HapticCues`): tick corto al empezar a grabar,
  double-tap al soltar. En paralelo con `RecordingSounds` por lo que
  vibración y pitido van sincronizados.
  Toggle en **Ajustes → Reproducción → Vibración al grabar**
  (default **on**).
- **Preview-before-send**: toggle en Ajustes. Si está on, al soltar
  el botón de grabar aparece una hoja con [▶ Reproducir] [Regrabar]
  [Enviar] y la duración. El fichero parqueado se borra al cancelar.
  Default **off** para no cambiar comportamiento actual.
- **Drag-to-reorder** (via flechas ↑/↓) de círculos secundarios
  desde Ajustes → Accesos rápidos. El primario no se reordena.
- **Bloqueo biométrico** opcional. Ajustes → Seguridad. Usa
  `androidx.biometric.BiometricPrompt` con ventana de gracia de 30s
  entre activities para no piotar al navegar dentro de la app.
- Corrección de **i18n residual**: literales "Historial", "No hay
  mensajes", "Volver" que estaban hardcoded en HistoryScreen /
  StatsScreen pasados a `stringResource`.

## 🔍 Changed

- `BaseLocaleActivity` ahora extiende `FragmentActivity` (antes
  `ComponentActivity`) porque `BiometricPrompt` necesita un
  FragmentManager host.
- Migración de DB **v7 → v8** (no destructiva): añade
  `settings.hapticEnabled`, `settings.previewBeforeSend`,
  `settings.biometricLockEnabled`.

## Install

Actualización desde 1.4.x. Al abrir la app por primera vez tras
actualizar no cambia nada visible: las tres features son opt-in.
