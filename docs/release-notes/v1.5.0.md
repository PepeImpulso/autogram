# v1.5.0 — UX polish (M2) ✨

Second roadmap milestone: vibration along with the beeps,
preview before sending, circle reordering, and optional
biometric lock.

## ✨ Added

- **Haptic feedback** (`HapticCues`): short tick when recording
  starts, double-tap on release. Runs in parallel with
  `RecordingSounds` so vibration and beep stay in sync.
  Toggle in **Settings → Playback → Vibration on recording**
  (default **on**).
- **Preview-before-send**: toggle in Settings. If on, releasing
  the record button brings up a sheet with [▶ Play] [Re-record]
  [Send] and the duration. The parked file is deleted on cancel.
  Default **off** to not change current behavior.
- **Drag-to-reorder** (via ↑/↓ arrows) of secondary circles
  from Settings → Shortcuts. The primary isn't reorderable.
- **Optional biometric lock**. Settings → Security. Uses
  `androidx.biometric.BiometricPrompt` with a 30s grace window
  between activities so it doesn't prompt while navigating within
  the app.
- Fix for **residual i18n**: literals "Historial", "No hay
  mensajes", "Volver" that were hardcoded in HistoryScreen /
  StatsScreen moved to `stringResource`.

## 🔍 Changed

- `BaseLocaleActivity` now extends `FragmentActivity` (previously
  `ComponentActivity`) because `BiometricPrompt` needs a
  FragmentManager host.
- DB migration **v7 → v8** (non-destructive): adds
  `settings.hapticEnabled`, `settings.previewBeforeSend`,
  `settings.biometricLockEnabled`.

## Install

Update from 1.4.x. On first open after the update nothing
visible changes: all three features are opt-in.
