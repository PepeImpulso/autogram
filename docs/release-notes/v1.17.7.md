# v1.17.7 — AA tile sizing finally lands (alpha anchor + native Badge) 🎯

v1.17.5 and v1.17.6 repeatedly tuned the fill-ratios in the avatar
bitmap (76% → 55% for secondaries, 96% → 100% for primary) expecting
the size difference to show up on the DHU. It kept not showing up.
The user was right to flag it. This release has the actual root
cause + fix.

## 🐛 Root cause — AA was cropping the transparent padding

AA's host (Gearhead) appears to trim each GridItem image bitmap to
its **opaque bounding box** before scaling it into the tile slot.
Our secondary bitmaps had a small opaque circle (radius = 55% × 768
≈ 423px) surrounded by hundreds of pixels of transparent padding.
The host cropped to the opaque region, scaled the 423px circle up
to fill the tile, and threw away the padding — so primary and
secondary ended up at the same on-screen size.

Verified by inspecting the `androidx.car.app:app:1.4.0` JAR:
GridItem supports a built-in `Badge` overlay via
`setImage(CarIcon, int, Badge)`, which confirms the host does its
own layout on top of the icon and doesn't render our bitmap
1:1 into the tile rect.

## ✨ Fix — alpha anchor + native Badge

- **Canvas anchor.** Every tile bitmap now starts with
  `canvas.drawColor(0x04000000)` — a 1.5%-alpha black wash across
  the full 768×768 canvas. Functionally invisible on AA's dark
  tile background, but it forces the host's opaque-bounds crop to
  include the full canvas. The circle's transparent padding now
  survives into the rendered tile, and primary vs secondary
  actually shows a ~2× size difference.
- **Native mic badge via AA's `Badge` API.** Removed the
  painted-in peach mic badge from the avatar bitmap; it's now
  rendered by the car host on top of the tile icon using
  `GridItem.Builder.setImage(icon, IMAGE_TYPE_LARGE, badge)` with
  a `Badge.Builder().setBackgroundColor(peach).setIcon(white
  mic)`. Host-side rendering means the badge stays crisp at any
  car-screen DPI and isn't crushed by AA's downscale of our
  bitmap.
- Same anchor-trick on the shortcut chip tiles: the chip no
  longer stretches to fill the tile — padding stays padding.

## 🔬 What this means visually

- **Merlin**: full-tile gold-ringed circle with a native peach
  mic dot in the corner.
- **Secondary circles (CSO / CFO / …)**: visibly ≈half the
  diameter, with the same native peach mic badge.
- **Shortcut chips**: dark-brown rounded pill at 94% of the tile,
  with a bold gold Bolt (text) or peach Mic (voice) icon at 60%
  of the chip.

## Install

Update from 1.17.6. Open Autogram in Android Auto — the size
difference between Merlin and the secondary circles should now
be obvious at a glance, not something you have to squint at. On
the 2024 Seat Ateca 9.2" screen the effect will be even more
pronounced than in the DHU preview.
