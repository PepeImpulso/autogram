# v1.4.2 — Stop Sentry from crashing the app at startup 💥

## 🐛 Fixed

- **Crash al arrancar** con DSN empty: `SentryInitProvider` se
  registra como `ContentProvider` que corre antes de
  `Application.onCreate`, lee el DSN del manifest y tira
  `IllegalArgumentException` si el string está vacío.
  Añadido `tools:node="remove"` en `AndroidManifest.xml` para ambos:
  - `io.sentry.android.core.SentryInitProvider`
  - `io.sentry.android.core.SentryPerformanceProvider`
  Sentry se inicializa ahora manualmente en `AutogramApplication.onCreate`,
  saltando grácilmente cuando el DSN no existe (dev builds).

## Install

Si la app te crasheaba al abrirse tras 1.4.x, actualiza a 1.4.2 y
vuelve a arrancarla.
