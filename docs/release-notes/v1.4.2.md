# v1.4.2 — Stop Sentry from crashing the app at startup 💥

## 🐛 Fixed

- **Startup crash** with empty DSN: `SentryInitProvider` registers
  as a `ContentProvider` that runs before `Application.onCreate`,
  reads the DSN from the manifest and throws
  `IllegalArgumentException` if the string is empty.
  Added `tools:node="remove"` in `AndroidManifest.xml` for both:
  - `io.sentry.android.core.SentryInitProvider`
  - `io.sentry.android.core.SentryPerformanceProvider`
  Sentry is now initialized manually in
  `AutogramApplication.onCreate`, gracefully skipping when the
  DSN doesn't exist (dev builds).

## Install

If the app was crashing on open after 1.4.x, update to 1.4.2 and
launch it again.
