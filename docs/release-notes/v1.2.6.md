# v1.2.6 — Recording cue volume 🎚

## ✨ Added

- **Volume slider** for the start/end recording beeps in
  Settings → Playback → Recording sounds. Some cars over-amplify
  the cue and it was annoying — now it can be lowered down to 0
  or disabled entirely with a toggle.
- **"Disable recording sounds" toggle**: if you want it 100%
  silent, one tap and done. Haptics (from M2.1) still fire
  independently.
