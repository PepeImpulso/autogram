# v1.32.3 — Up-to-date Android Auto History 🕘

Android Auto History now refreshes as messages arrive and includes incoming
text messages alongside voice notes.

## 🐛 Fixed

- **History refreshes while connected (#7).** Android Auto is notified when
  the recent history changes, including on the initial subscription after
  reconnecting, so its cached folder can reload current messages.
- **Recent text replies appear in History.** The previous voice-only filter
  omitted messages read aloud through text-to-speech. History now includes
  incoming audio, text, and retained transcription or summary fallbacks,
  using the existing playback actions.
- **The latest 50 eligible messages are selected in the database.** Filtering
  happens before the limit and sorting is newest first, so outgoing traffic
  cannot crowd incoming messages out of the list.

## 🧪 Tests

- **History flow regression coverage.** Checks initial load, text arrivals,
  audio cleanup with a retained transcript, and reopening History.
- **SQLite query checks.** Verify mixed content, newest-first ordering,
  filtering before the limit, inserts, and deletes.

## Install

Update through Autogram's in-app updater, then open History in Android Auto
and check the latest incoming voice and text replies.
