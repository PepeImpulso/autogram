# v1.4.1 — Bake Sentry DSN into the APK 🔑

Version bump sin cambios de código. El build pipeline pasado no había
leído el DSN de Sentry que acababa de configurarse en `local.properties`
porque el APK v1.4.0 se firmó antes de que estuviera el secret. Esta
versión solo existe para que el APK recompile con `BuildConfig.SENTRY_DSN`
ya presente.

## 🐛 Fixed

- `BuildConfig.SENTRY_DSN` ahora llega a producción — Sentry captura
  eventos reales de crash + breadcrumbs de Timber.e/.w.

## Install

Actualizar desde 1.4.0 para empezar a ver los crashes en el dashboard
de Sentry. Sin cambios funcionales aparte del reporting.
