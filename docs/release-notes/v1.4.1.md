# v1.4.1 — Bake Sentry DSN into the APK 🔑

Version bump with no code changes. The previous build pipeline
hadn't read the Sentry DSN that had just been configured in
`local.properties` because the v1.4.0 APK was signed before the
secret was in place. This version only exists so the APK is
rebuilt with `BuildConfig.SENTRY_DSN` already present.

## 🐛 Fixed

- `BuildConfig.SENTRY_DSN` now reaches production — Sentry
  captures real crash events + Timber.e/.w breadcrumbs.

## Install

Update from 1.4.0 to start seeing crashes on the Sentry
dashboard. No functional changes beyond the reporting.
