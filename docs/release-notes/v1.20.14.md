# v1.20.14 — Louder beeps, debug screenshots, listen-from-badge

Three independent UX improvements requested after testing v1.20.13.

## Changed

- **Recording beep is now 2× louder** at every slider value. The
  start/stop tones were inaudible over road noise even at the default
  50% setting. The slider's 0–50 range now covers the full effective
  loudness; 51–100 stays clamped at the system MEDIA-stream cap.

## Added

- **Tapping a per-circle pending badge opens that circle's History.**
  When a circle on the Home screen shows a red "1" (or higher) for
  unanswered incoming messages, tapping that badge now opens the
  History view scoped to that conversation — so you can finally listen
  to / read the messages the badge is counting. Opening the History
  also acts as an acknowledgement: the badge clears once you've seen
  the messages, even if you don't reply yet.
- **Developer-mode screenshot button.** Settings → Diagnostics →
  *Developer mode* (off by default). When ON, a small camera button
  appears next to the play-last-original toggle in the home-screen
  header. Tap it to capture the current screen, save it to the
  Pictures/Autogram folder in your gallery, and immediately open the
  system share sheet — pick Telegram (or any other app) to forward
  the screenshot to the developer for bug-report context.

## Install

Update from Autogram's in-app updater. Schema migrates 16 → 17 to
add the new `developerMode` column. No new permissions: the screenshot
flow uses MediaStore on API 29+, which doesn't require runtime storage
permissions for our own pictures.
