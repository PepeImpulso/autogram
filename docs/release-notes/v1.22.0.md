# v1.22.0 — Cross-conversation History/Pending + recording-vs-playback fix

Three connected fixes for issues you hit on v1.21.0, all driven by
the same observation: the playback control had to be reachable from
the screen you're actually looking at, regardless of which
conversation initiated the audio.

## Fixed

- **Stop button reachable in History/Pending.** v1.21.0's History tab
  was scoped to a single conversation, so when autoplay started a
  message from a different chat the row never rendered and there
  was no visible pause control. History is now a cross-conversation
  log: every voice + text message from every chat, sorted
  newest-first. The currently-playing message is therefore always
  visible, and its row's play/pause toggle works.
- **Autoplay never speaks over an in-flight recording.** While the
  mic is hot, incoming voice / text replies are deferred to the
  pending queue with a new `USER_RECORDING` reason instead of
  starting playback that would (a) talk over you mid-record and (b)
  leak into the recording's own audio. When you stop or cancel the
  recording, the queue resumes if you have auto-play on, or stays
  parked for manual drain if not — exactly the rule you asked for.

## Changed

- **History + Pending: cross-conversation lists with avatar-on-left
  rows.** Both tabs now show a flat list of every message from every
  contact, with the contact's avatar on the left (matching the Now
  Playing drawer's visual language), name + subtitle in the middle,
  and a play/pause toggle on the right. Outgoing messages share the
  same row layout with a "Sent: …" prefix on the subtitle.
- **Contact filter chips at the top of both tabs.** A scrollable
  chip row lets you filter both tabs to a single contact (or "All").
  Tapping a per-circle pending badge on Home still pre-filters
  History to that circle as before.
- **Pending tab: dropped the All/Voice/Text type filter** — it was
  redundant with the per-message rendering and competing for the
  same screen real estate as the new contact filter.
- **History tab: dropped the chat-bubble layout** in favor of the
  unified row design. The conversation-chooser dropdown in the
  toolbar is gone too — its job is now done by the chip row, with
  more affordance and less hunting.
- **History tab: "Clear conversation" only surfaces when a specific
  contact filter is set.** Wiping every conversation at once is too
  destructive for a single tap.
- **Tab badge counts total pending across all contacts.** Was
  showing the filtered count which was confusing when the active
  filter excluded most of the queue.

## Internal

- **`PendingReason.USER_RECORDING`** — new enum value distinguishing
  records deferred because the user is recording from records
  deferred for silent mode / in-call. No DB migration needed (Room
  stores enums by name; old rows keep their existing values).
- **`PlayReplyUseCase` injects `AudioRecorder`** and gates the three
  autoplay entry points (`playVoiceMessage`,
  `playSummaryOrTranscription`, `playTextMessage`) on
  `audioRecorder.isRecording()`. New `drainPendingIfAutoPlay()`
  helper resumes the queue after recording terminates; called from
  `SendVoiceMtprotoUseCase.cancelRecording`,
  `SendVoiceMtprotoUseCase.stopAndSend` (non-preview paths only),
  `cancelPreview` and `confirmPreview`.
- **`HistoryViewModel`** rewritten around
  `MessageRepository.observeAllAcrossConversations()` plus a
  `contactFilter: StateFlow<String?>`. The old per-conversation
  scope is gone; the home-screen `EXTRA_CONVERSATION_ID` extra is
  honored by setting the initial filter so the per-circle-badge
  flow lands you pre-filtered.
- **`PendingQueueViewModel`** swapped the `QueueFilter` (All/Voice/
  Text) enum for the same `contactFilter: StateFlow<String?>` shape
  used by History. Added a separate `totalQueue` StateFlow so the
  tab-bar badge can show the unfiltered count.
- **`SharedMessageUi.kt`** (new) — extracted `MessageRow` and
  `ContactFilterRow` so both tabs render the same row shape and
  chip strip. Drops `MessageBubble`, `AudioBubbleHeader`,
  `OutgoingAudioHeader`, `bubbleShape`, `groupByDay`, `DayDivider`,
  the `InlineBlock` family, and the `QueueRow` specific to Pending.
- **2 new strings localized to all 7 locales:** `contact_filter_all`
  and `history_row_sent_prefix`.
