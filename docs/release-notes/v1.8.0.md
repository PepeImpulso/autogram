# v1.8.0 — On-device transcription (M4 #1) 📝

Fourth roadmap milestone, first item: automatic transcription
of incoming voice notes using Android's on-device
`SpeechRecognizer` (the Google model your phone already ships
with). No external services, no APK bloat.

## ✨ Added

- **`TranscriptionEngine`** interface in
  `infrastructure/transcription/`. Hilt binds to
  **`AndroidOnDeviceTranscriptionEngine`**, which:
  1. Decodes the OGG/Opus via `MediaExtractor` + `MediaCodec`.
  2. Downmixes stereo → mono, resamples to 16 kHz linear.
  3. Passes the PCM as a `ParcelFileDescriptor` to
     `SpeechRecognizer.createOnDeviceSpeechRecognizer()` with
     `RecognizerIntent.EXTRA_AUDIO_SOURCE`.
- **`TranscribeVoiceUseCase`** chained from
  `MtprotoReceiverService.handleVoiceNote`. Idempotent (checks
  `transcription` and `transcriptionState` before running).
- **Toggle** in Settings → Transcribe voice messages. Grayed out
  on Android < 14 (`EXTRA_AUDIO_SOURCE` is API 34+).
- **History**: shows the transcribed text in italics below the
  audio, with a spinner while transcribing and an error message
  if the language pack isn't installed.

## 🔍 Changed

- `Message` gains `transcription: String?` +
  `transcriptionState: TranscriptionState` (NONE / PENDING /
  IN_PROGRESS / DONE / FAILED / UNAVAILABLE).
- `AppSettings` gains `transcribeIncomingVoice: Boolean = false`.
- DB migration **v9 → v10** (non-destructive): 3 new columns.

## Architecture

Decision: on-device (SpeechRecognizer) instead of Whisper.cpp
because the APK doesn't grow (Whisper base = 142 MB), it's
maintained by Google, and the S25+ supports it out of the box.
The interface allows us to plug Whisper in later by swapping a
`@Binds` in Hilt if quality ever turns out to be insufficient.

## Install

Requirements:
- Android 14+ (the API for feeding audio-from-file to the
  recognizer is API 34+).
- Google Speech language pack installed (otherwise Android
  offers to download it on first use).
