# v1.8.0 — Transcripción on-device (M4 #1) 📝

Cuarto milestone del roadmap, primer item: transcripción automática
de notas de voz entrantes usando el `SpeechRecognizer` on-device de
Android (el modelo de Google que ya lleva tu móvil). Sin servicios
externos, sin APK bloat.

## ✨ Added

- **`TranscriptionEngine`** interface en
  `infrastructure/transcription/`. Hilt bind a
  **`AndroidOnDeviceTranscriptionEngine`** que:
  1. Decodifica el OGG/Opus via `MediaExtractor` + `MediaCodec`.
  2. Downmixea estéreo → mono, resamplea a 16 kHz linear.
  3. Pasa el PCM como `ParcelFileDescriptor` a
     `SpeechRecognizer.createOnDeviceSpeechRecognizer()` con
     `RecognizerIntent.EXTRA_AUDIO_SOURCE`.
- **`TranscribeVoiceUseCase`** encadenado desde
  `MtprotoReceiverService.handleVoiceNote`. Idempotente (comprueba
  `transcription` y `transcriptionState` antes de correr).
- **Toggle** en Ajustes → Transcribir mensajes de voz. Grayed-out
  en Android < 14 (`EXTRA_AUDIO_SOURCE` es API 34+).
- **History**: muestra el texto transcrito en cursiva bajo el
  audio, con spinner mientras transcribe y mensaje de error si el
  pack de idioma no está instalado.

## 🔍 Changed

- `Message` gana `transcription: String?` + `transcriptionState:
  TranscriptionState` (NONE / PENDING / IN_PROGRESS / DONE /
  FAILED / UNAVAILABLE).
- `AppSettings` gana `transcribeIncomingVoice: Boolean = false`.
- Migración de DB **v9 → v10** (no destructiva): 3 columnas
  nuevas.

## Arquitectura

Decisión: on-device (SpeechRecognizer) en vez de Whisper.cpp porque
el APK no crece (Whisper base = 142 MB), está mantenido por Google,
y el S25+ lo soporta out-of-the-box. La interface permite enchufar
Whisper después cambiando un `@Binds` en Hilt si alguna vez la
calidad resulta insuficiente.

## Install

Requisitos:
- Android 14+ (la API de feeding audio-from-file al recognizer es
  API 34+).
- Pack de idioma de Google Speech instalado (si no, Android lo
  ofrece descargar al primer uso).
