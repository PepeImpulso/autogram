# v1.20.11 — Pending-playback UX rebuild

The pending-message flow had four parallel sub-systems that didn't talk
to each other: a silent-mode toggle that queued messages with no in-app
way to drain them, an auto-play toggle that silently dropped messages,
a launcher icon badge counting notifications instead of pending playback,
and a separate "show pending badges" setting that only controlled the
red dots on the home circles. This release rebuilds the whole surface
around a single coherent model.

## Changed

- **Silent mode and auto-play replies are now one setting.** `Settings →
  Auto-play replies`. ON: incoming voice + text replies play out loud as
  they arrive (the historical default). OFF: every reply is queued for
  later playback from the new "▶ N pending" button on the home screen.
  The old "silently drop the message" behaviour is gone — `autoPlay=OFF`
  used to mean "no audio AND no queue", which left messages stuck in
  RECEIVED state with no surface anywhere. Existing users with
  `silentMode=ON` (or `autoPlayReplies=OFF`) get migrated to the new
  `autoPlayReplies=OFF` automatically.
- **New "▶ N pending" button on the Home hero header** (left of the
  headphones icon). Visible only when the queue has items. Tap to drain
  every pending message sequentially via the existing playback chain.
  The headphones icon still does what it always did — replays only the
  most-recent message — and is now labelled *"Replay last"* / *"Repetir
  último"* to make the distinction clear.
- **History → tap on a pending row now drains from there.** Tapping a
  message in `MessageState.PENDING_PLAYBACK` plays that message via the
  queue path and chains through the rest of the queue, instead of
  playing one isolated message and leaving the rest stuck.
- **Launcher icon badge stays in sync with what's in the app.** Two
  fixes: (a) `MainActivity.onResume` cancels every in-flight per-
  conversation incoming-message notification, so the launcher badge
  clears the moment you open the app; (b) the `Show pending badges`
  setting now also controls the launcher-icon badge dot — toggling it
  off finally removes ALL badges, including the one on the launcher.
