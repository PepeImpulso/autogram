# v1.29.3 — Steadier car grid after sending 🚗🛠️

Two fixes from real use of v1.29.2: the car grid sometimes said it could not
load the contacts right after a send, and an interrupted voice playback was
reported to Sentry as an error.

## 🐛 Fixed

- **Car grid no longer comes up as "can't load" after a send.** A send
  changes the state several times within a second (sending, sent, unread
  counters), and each change asked Android Auto to reload the grid. When one
  of those reloads failed or its contacts query was slow, the car kept the
  failed grid until the next incoming message refreshed it. Now the reloads
  are grouped into one per burst, and a failed or slow reload reuses the
  last good grid instead of showing an error. Failures are now reported to
  Sentry as errors, so if it still happens we can see why.
- **No false "Failed to play audio" errors.** When a playback was stopped or
  replaced by a newer message while Android was still preparing it,
  MediaPlayer threw `IllegalStateException` and Autogram reported it as a
  crash-level error (Sentry 304c077f). That case is expected and is now
  logged as information; real playback failures are still reported.

## Install

Update through Autogram's in-app updater.
