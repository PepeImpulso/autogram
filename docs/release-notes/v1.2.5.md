# v1.2.5 — Android Auto launcher hardening 🚗

## 🐛 Fixed

- **Launcher visibility on Android Auto with "projected" hosts**.
  On some cars (hosts that project the head unit from the phone)
  the app wasn't appearing in the grid even though `IOT` was
  declared. Hardened the `AndroidManifest` with the correct
  `CarAppService` metadata + explicit projection support
  declaration, without touching the normal launcher flow.

The fix only affects AA visibility — the rest of the app stays
identical.
