# v1.4.3 — "Send test event to Sentry" from Diagnostics 🐞

Pequeña mejora de operabilidad de Sentry: una forma rápida de
comprobar que el tracker está funcionando sin necesidad de provocar
un crash real.

## ✨ Added

- **Ajustes → Diagnóstico → Enviar evento de prueba a Sentry**.
  Dispara un `RuntimeException` capturado via `Sentry.captureException`
  con el mensaje "Test event from Ajustes → Diagnóstico". La sección
  solo aparece cuando hay `BuildConfig.SENTRY_DSN` — en builds sin
  DSN (dev) queda oculta.
- Tras tap: feedback "Test event sent ✓" durante 3 s bajo el botón.

## Install

Actualización en sitio desde 1.4.x. Tras actualizar, abrir Ajustes
→ Diagnóstico para verificar que Sentry está conectado.
