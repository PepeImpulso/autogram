# v1.4.3 — "Send test event to Sentry" from Diagnostics 🐞

Small Sentry operability improvement: a quick way to verify the
tracker is working without having to trigger a real crash.

## ✨ Added

- **Settings → Diagnostics → Send test event to Sentry**. Throws
  a `RuntimeException` captured via `Sentry.captureException`
  with the message "Test event from Settings → Diagnostics". The
  section only appears when `BuildConfig.SENTRY_DSN` is set — on
  builds without a DSN (dev) it's hidden.
- After tap: "Test event sent ✓" feedback for 3s below the
  button.

## Install

In-place update from 1.4.x. After updating, open Settings →
Diagnostics to verify Sentry is connected.
