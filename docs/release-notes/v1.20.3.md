# v1.20.3

Audit release after another deep pass on Android Auto, startup flow, and
launch-surface security.

## Fixed

- Quick Settings auto-record intents are now authenticated with a one-time
  app-private token. `MainActivity` is launcher-exported, so extras alone were
  not enough — another app could have forged `EXTRA_AUTO_RECORD` and triggered
  recording. The tile now issues a one-shot token and `MainActivity` consumes
  it before honoring the request.
- First-run onboarding now short-circuits the rest of `MainActivity.onResume`.
  Before this, a fresh install could launch the onboarding flow and still keep
  starting the MTProto foreground service + companion permission prompts behind
  it.
