# v1.29.0 — Experimental in-grid car buttons, opt-in 🧪🚗

v1.28.1 brought the contacts back to the car by turning off the in-grid
record/send buttons. This release brings those buttons back as an opt-in
setting, so they can be tried on a real car and switched off from the phone
if the grid empties again, without waiting for a new release.

## ✨ Added

- **Settings → Android Auto → "Car grid buttons (experimental)".** OFF by
  default. When ON, each contact tile in the car's "Grabar" grid gets a mic
  button to start recording, then send ➤ and cancel ✕ while recording, so
  you never leave the grid. These are Android Auto "custom browse actions":
  Android Auto draws them itself and they can't be tested on the emulator,
  which is why they stay off unless you turn them on.

## 🔍 Changed

- **The setting applies when Android Auto connects.** Autogram tells Android
  Auto whether to show the buttons only at connection time, so after
  toggling, disconnect and reconnect the phone (or restart Android Auto).

## Install

Update through Autogram's in-app updater. Nothing changes in the car until
you turn the new setting on. If the car's Grabar grid comes up empty with it
on, turn it off and reconnect Android Auto.
