# v1.20.22 — Drag-and-drop reordering for shortcuts

Reorder the shortcuts on your Home screen by dragging them in the
Shortcuts editor.

## Added

- **Drag handle on every shortcut card.** Each row in *Shortcuts* now
  has a small drag-handle icon on the leading edge. Press and drag
  it to move the shortcut up or down in the list — releases the row
  in the new spot, persists the order to the database, and the Home
  screen's chip row re-orders to match. Auto-scrolls when the
  dragged row reaches the top or bottom edge of the list. The card
  itself stays clickable for the existing tap-to-edit behaviour;
  only the drag handle starts a reorder.

## Internal

- **`QuickReplyRepository.reorder(orderedIds)`.** New repository
  method that writes `position = index` for each id in the supplied
  order. Implemented in two phases (push everyone past the current
  max, then write the final 0..N-1) so the editor's `ORDER BY
  position ASC` Flow never observes a state with two shortcuts
  sharing a position mid-write.
- **Dep: `sh.calvin.reorderable:reorderable:2.4.3`.** Used for the
  drag-handle gesture + LazyColumn auto-scroll while dragging — the
  rest is hand-rolled (draft order during drag, persist on drop).
