# v1.14.0 — Rediseño premium de History, Stats, Atajos rápidos & PinnedPicker 🎨

Completa el tratamiento visual premium en toda la app. Todas las
pantallas comparten ahora el mismo lenguaje: `ElevatedCard`s sobre
fondo `surfaceContainerLow`, badges circulares de icono, empty-state
ilustrado y copy totalmente localizado.

## ✨ HistoryScreen — layout de burbujas de chat

- Mensajes renderizados como burbujas alineadas a la **izquierda**
  (entrantes) o **derecha** (salientes) — la dirección se lee de un
  vistazo sin depender de badges. Radio de esquina asimétrico (plana
  en el lado de la conversación) da a cada burbuja un hint claro
  sin necesitar cola/flecha.
- Headers de audio dentro de las burbujas: `FilledIconButton`
  play/pause + label de duración — ya no hay un botón trailing
  colgado fuera del card.
- Separadores de día con Hoy / Ayer / fecha explícita para que los
  scrolls largos sean orientables.
- Bloques de resumen + transcripción comparten el componente
  `InlineBlock` para que la gramática visual sea consistente
  ("pill indentado = contenido derivado").
- Label de estado + hora colapsados en una fila footer discreta.
- Empty state premium: icono Forum en burbuja circular
  `surfaceVariant` + subtítulo explicativo.
- Eliminados strings hardcoded en español ("Saliente", "Entrante",
  todas las ramas de `stateLabel(...)`, content-descriptions de
  playback); ahora todo localizado en 6 locales.

## ✨ StatsScreen — metric cards + chart surface

- 4 metric cards (Enviados / Recibidos / Tasa de éxito / Duración
  media) cada uno con badge circular tintado y número en bold.
  Layout 2x2 que escala limpio en cualquier ancho de móvil.
- Chart de 7 días vive ahora dentro de una `ElevatedCard` con su
  header (título + subtítulo) y legend footer. Barras apiladas con
  esquinas redondeadas arriba-y-abajo que solo aparecen cuando esa
  porción existe — un día con solo "enviados" se lee como una pill
  limpia.
- Legend localizado (antes hardcoded "Enviados" / "Recibidos").
- Empty state premium: icono Insights + subtítulo explicativo.

## ✨ QuickRepliesSettingsActivity — cards + icon badges

- Reemplazadas filas `ListItem` con `ElevatedCard`s que tienen badge
  Bolt tintado `primary` a la izquierda, label bold + supporting
  text muted en medio, lápiz hint + trash action a la derecha. Tap
  en el card para editar, tap en la trash para borrar.
- Empty state con icono Bolt en burbuja circular.
- Spacer 72dp inferior para que el último card no se esconda bajo
  el FAB.

## ✨ PinnedPickerActivity — espeja el rediseño de TargetPicker

- Lista de chats basada en cards con icono por tipo (Person / Groups
  / Forum).
- Paso multi-topic: los cards llevan su checkbox a la izquierda,
  icono tag/lock en `secondaryContainer`, título + tag chips.
  Cards seleccionados adoptan fondo `primaryContainer` tintado para
  que la selección sea visible; las filas del topic primario tienen
  fondo `tertiaryContainer` + badge estrella para indicar que están
  bloqueadas.
- Campo de búsqueda + clear; misma lógica de empty state no-match
  vs no-items que TargetPicker.

## 🌐 Strings

20+ keys nuevas localizadas a los 6 idiomas soportados (estados de
history, labels de dirección, separadores de día, legend de stats,
hints de búsqueda del picker, subtítulo del chart). Cero literales
hardcoded residuales.

## Install

Actualización desde 1.13.x. Los rediseños son puramente visuales
— no hay cambios de esquema ni flags de usuario.
