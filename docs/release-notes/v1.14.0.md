# v1.14.0 — Premium redesign of History, Stats, Quick Replies & PinnedPicker 🎨

Completes the premium visual treatment across the whole app.
All screens now share the same language: `ElevatedCard`s over
`surfaceContainerLow` background, circular icon badges,
illustrated empty states and fully localized copy.

## ✨ HistoryScreen — chat-bubble layout

- Messages rendered as bubbles aligned **left** (incoming) or
  **right** (outgoing) — the direction reads at a glance
  without relying on badges. Asymmetric corner radius (flat on
  the conversation's side) gives each bubble a clear hint
  without needing a tail/arrow.
- In-bubble audio headers: `FilledIconButton` play/pause +
  duration label — no more trailing button dangling outside
  the card.
- Day separators with Today / Yesterday / explicit date so
  long scrolls are navigable.
- Summary + transcription blocks share the `InlineBlock`
  component so the visual grammar stays consistent ("indented
  pill = derived content").
- Status label + time collapsed into a discreet footer row.
- Premium empty state: Forum icon in a `surfaceVariant` round
  bubble + explanatory subtitle.
- Removed hardcoded Spanish strings ("Saliente", "Entrante",
  all branches of `stateLabel(...)`, playback
  content-descriptions); now all localized across 6 locales.

## ✨ StatsScreen — metric cards + chart surface

- 4 metric cards (Sent / Received / Success rate / Average
  duration) each with a tinted circular badge and number in
  bold. 2x2 layout that scales cleanly across any phone width.
- The 7-day chart now lives inside an `ElevatedCard` with its
  header (title + subtitle) and legend footer. Stacked bars
  with rounded top-and-bottom corners that only appear when
  that portion exists — a day with only "sent" reads as a
  clean pill.
- Localized legend (previously hardcoded "Enviados" /
  "Recibidos").
- Premium empty state: Insights icon + explanatory subtitle.

## ✨ QuickRepliesSettingsActivity — cards + icon badges

- Replaced `ListItem` rows with `ElevatedCard`s that have a
  Bolt badge tinted `primary` on the left, bold label +
  muted supporting text in the middle, pencil hint + trash
  action on the right. Tap the card to edit, tap the trash to
  delete.
- Empty state with Bolt icon in a round bubble.
- 72dp bottom spacer so the last card doesn't hide under the
  FAB.

## ✨ PinnedPickerActivity — mirrors the TargetPicker redesign

- Card-based chat list with per-type icon (Person / Groups /
  Forum).
- Multi-topic step: cards carry their checkbox on the left, a
  tag/lock icon in `secondaryContainer`, title + tag chips.
  Selected cards take a tinted `primaryContainer` background
  so selection is visible; primary-topic rows have a
  `tertiaryContainer` background + star badge to indicate
  they're locked.
- Search field + clear; same no-match vs no-items empty-state
  logic as TargetPicker.

## 🌐 Strings

20+ new keys localized into the 6 supported languages (history
states, direction labels, day separators, stats legend,
picker search hints, chart subtitle). Zero residual hardcoded
literals.

## Install

Update from 1.13.x. The redesigns are purely visual — no
schema changes or user flags.
