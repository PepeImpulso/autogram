# v1.25.0 — Ready for Google Play 🚗

This release prepares Autogram for Google Play while preserving the standalone
GitHub distribution and its existing signing identity.

## ✨ Added

- **Google Play distribution.** A dedicated Play flavor produces a signed App
  Bundle without the standalone updater or package-install permission, allowing
  Google Play to manage updates safely.
- **Local data controls.** Settings now links to Autogram's privacy policy and
  lets users disconnect Telegram and erase the local session, conversations,
  recordings, shortcuts, settings, and diagnostics.
- **External AI disclosure.** Autogram now explains when selected message text
  will leave the device and requires explicit consent before enabling a custom
  LLM endpoint.

## 🔍 Changed

- **Current Android compatibility.** The app now targets Android 16 (API 36) so
  it meets the latest platform and Google Play requirements.
- **Play privacy defaults.** Google Play builds disable automatic Sentry crash
  reporting and require HTTPS for user-configured AI endpoints.
- **Settings scrolling.** Scrolled settings content is clipped below the app bar
  so it can no longer cover the title and navigation control.

## 🧪 Tests

- **Distribution coverage.** Both GitHub and Google Play variants are compiled
  and tested independently, with lint and manifest checks applied to the final
  Play bundle.

## Install

Existing standalone installations can move to Google Play only when Play App
Signing is enrolled with Autogram's current release certificate.
