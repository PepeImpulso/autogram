# v1.17.0 — Voice shortcuts 🎤⚡

Text-only quick replies had a workflow cost: tap a text chip, the
assistant on the other end answers with text. Some users (and some
assistants) prefer voice-to-voice. v1.17.0 adds a second kind of
shortcut — **pre-recorded voice notes** — and a small filter so you
can bias the home screen toward text, voice, or both.

## ✨ Added

- **Voice shortcuts.** Record once, tap forever. In Settings →
  Shortcuts, the "+" FAB now opens a sheet asking for the kind
  (Text or Voice). Voice flow: label + Record → Stop → Preview /
  Redo → Save. The recording is saved as a `.ogg/Opus` voice note
  under `filesDir/voice_shortcuts/<id>.ogg` and reused on every tap.
- **Mic icon on the home screen** for voice shortcut chips (text
  chips keep the Bolt icon). Tap a voice chip → the pre-recorded
  clip is sent to the primary target as a real voice note via
  TDLib, same pipeline as a fresh recording.
- **Shortcut filter row.** When both kinds are configured, a small
  FilterChip row appears above the primary circle: All / Text /
  Voice. The selection persists in settings so it survives
  restarts. If you only have one kind, the row hides itself.
- **Edit-without-rerecord.** Editing a voice shortcut's label keeps
  the existing recording; only explicit Record / Redo creates a
  new take.

## 🔍 Changed

- **Schema v13 → v14** (non-destructive): `quick_replies` gains
  `kind`, `audioFilePath`, `audioDurationMs`; `settings` gains
  `quickReplyFilter`. Existing text shortcuts keep kind=`TEXT`
  and continue to work unchanged.
- **Offline behavior.** A voice-shortcut tap while offline copies
  (doesn't move) the `.ogg` into `audio_outbox/` so the original
  shortcut stays playable. RetryWorker picks the queued copy up
  when network returns.
- Strings localized to all 6 supported locales.

## 🐛 Fixed

Found and fixed during audit, before shipping:

- **Atomic saveVoice.** Previous sequence `dst.delete → copy →
  src.delete` had a data-loss window if copy threw: the old
  recording was gone and no replacement existed. Now: copy to a
  `.new` staging file next to dst, rename over dst, only then
  delete src. On copy failure the original shortcut survives
  intact.
- **Recorder off the Main thread.** `MediaRecorder.prepare()+start()`
  can block 50-300 ms on some OEMs. Moved start + stop to
  `Dispatchers.IO` so the Record button doesn't jank while Compose
  is recomposing.
- **Resource cleanup on dialog dispose.** `DisposableEffect`
  guarantees the recorder/player is released when the Voice
  editor leaves composition for any reason — save, cancel, back
  press, or rotation.
- **Explicit target id for shortcut sends.** The chip tap now
  passes `primary.id` through, matching the pre-refactor behavior
  for text chips where the primary conversation was always the
  intended target.

## Install

Update from 1.16.x. No data migration needed beyond the
non-destructive ALTER TABLE. Existing shortcuts remain text-only
until you convert them via Settings → Shortcuts (or add new voice
ones alongside).
