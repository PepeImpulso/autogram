# v1.27.1 — Mark all as listened from the History header ✅

Small convenience release: the most-used action on the History screen is
now one tap away from either tab.

## ✨ Added

- **"Mark all as listened" in the top-right corner.** The History screen's
  header has a ✓✓ button that clears every pending message after a
  confirmation, from both the Pending and History tabs. It is greyed out
  when nothing is pending. The existing button inside the Pending tab stays.

## Install

Update through Autogram's in-app updater; no configuration changes are needed.
