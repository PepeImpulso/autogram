# v1.4.0 — Reliability & observability (M1) 🛡️

First milestone of the 16-improvement roadmap. Laid the
reliability infrastructure (offline queue, audio cleanup, crash
reporting) without touching anything user-visible yet.

## ✨ Added

- **`ConnectivityObserver`** wraps `ConnectivityManager.registerDefaultNetworkCallback`
  as a `StateFlow<Boolean>`. Every piece of the system now knows
  whether there is connectivity without polling.
- **`MessageState.QUEUED_OFFLINE`** — new state for messages the
  user sent without network or without TDLib authenticated.
- **`RetryWorker`** (WorkManager) with `NetworkType.CONNECTED`
  constraint. Drains the outbox with exponential backoff up to
  `settings.maxRetryAttempts`. Fires after enqueueing and at app
  startup, and by the constraint when the network returns.
- **`RetentionCleanupWorker`** extended: a second sweep that
  compares files in `audio_incoming/`, `audio_outbox/` and
  `audio_outgoing/` against each `messages` row's `audioFilePath`.
  Deletes orphans (crashes, re-installs, purged rows).
- **`settings.autoDeletePlayed` toggle** (default **on**): deletes
  a received voice note's `.ogg` when its playback finishes.
- **Sentry** (`io.sentry:sentry-android`) with
  `SentryTimberIntegration`. `Timber.e` → events, `Timber.w` →
  breadcrumbs. DSN in `local.properties` →
  `BuildConfig.SENTRY_DSN`, not committed.

## 🔍 Changed

- Outbox: tapping **Send** without network or without
  `AuthState.Ready`, the message enters `QUEUED_OFFLINE` instead
  of `FAILED`. The status pill becomes "N queued · will send on
  reconnect".
- DB migration **v5 → v6 → v7** (non-destructive): adds
  `settings.autoDeletePlayed`.

## Install

The auto-updater (Settings → Check for updates) detects 1.4.0
over any 1.2.x / 1.3.x and offers to download this APK.
