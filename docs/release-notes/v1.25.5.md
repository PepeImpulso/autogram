# v1.25.5 — Clearer Hermes audio in the car 🔊

This release prevents Telegram voice replies from being forced onto a
telephone-quality Bluetooth route and adds diagnostics for any remaining
device-specific playback problems.

## 🐛 Fixed

- **Voice replies no longer force Bluetooth SCO.** SCO is intended for
  telephony and could make Hermes Agent's low-bitrate Opus replies sound
  robotic through the car; Autogram now leaves routing to Android when no
  suitable media output is available.

## 🔍 Changed

- **Audio failures are easier to diagnose.** Playback logs now include the
  detected format, sample rate, channel count, bitrate, duration, car state,
  audio attributes, playback speed, and actual output route without recording
  message contents.

## 🧪 Tests

- **SCO routing has regression coverage.** A dedicated test verifies that
  Autogram never selects the telephony route for media voice playback.
- **Both distributions verified.** The GitHub and Google Play unit-test suites
  and Android lint tasks pass.

## Install

Update through Autogram's in-app updater, then compare one Hermes voice reply
and one OpenClaw voice reply while connected to the car.
