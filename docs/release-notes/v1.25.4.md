# v1.25.4 — Reliable replies in Android Auto 🚗

This release hardens the complete incoming-reply path so text and audio are
not silently lost, acknowledged, or routed away from the car speakers.

## 🐛 Fixed

- **Android Auto no longer shuts down active TTS.** Hiding the phone UI is a
  normal projection transition, so it no longer destroys the speech engine or
  strands the current message.
- **Audio-focus interruptions preserve unheard replies.** Denied or lost focus
  now stops the matching playback generation once and returns the message to
  the pending queue instead of marking it as heard.
- **Rapid and long text replies play sequentially.** Accepted TTS requests are
  tracked before speech starts, long replies are split at natural boundaries,
  and stale callbacks cannot clear or replace a newer message.
- **Voice attachments from agents are recognized.** Telegram voice notes,
  audio messages, and audio documents—including files with a generic MIME
  type—now share the same playback path.
- **Receiver gaps no longer discard ordinary in-process arrivals.** Incoming
  updates use a buffered FIFO channel, stable Telegram-derived IDs prevent
  duplicate playback, downloads retry transient failures, and a cancelled
  receiver returns its in-flight update to the channel.
- **Call-end playback is race-safe.** Pending replies resume after a call, but
  the delayed drain is cancelled if another call begins first.
- **Car routing stays on a speech-appropriate path.** Voice and TTS navigation
  prompts use speech attributes, brief projection-provider gaps preserve the
  last known car connection, and Autogram notifications no longer compete for
  audio focus with their own playback.

## 🔍 Changed

- **Pending playback remains durable until completion.** Queue rows are removed
  only after a successful terminal callback; process interruptions and explicit
  Stop actions return unfinished content to the queue.
- **Queue controls are serialized.** Repeated Play All, Stop, skip, and manual
  replacement actions cannot start two items or let an older callback mutate a
  newer playback session.

## 🧪 Tests

- **Playback regression coverage expanded.** New tests cover focus denial,
  durable completion, stale callbacks, repeated queue controls, interrupted
  restoration, long-text chunking, route selection, and car-state fallback.
- **Telegram routing coverage expanded.** Tests cover exact topic routing,
  duplicate precedence, stable message IDs, audio/document classification, and
  transient download errors.
- **Both distributions verified.** The GitHub and Google Play unit-test suites
  and Android lint tasks pass.

## Install

Update through Autogram's in-app updater, then test one text reply and one
voice/audio reply in Android Auto from both Merlin and Hermes.
