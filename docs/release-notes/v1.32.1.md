# v1.32.1 — Readable update notes 📜

The "New version available" dialog now shows the full release notes and
lets you scroll through them.

## 🐛 Fixed

- **Long release notes were cut off and could not be scrolled.** The
  dialog capped the height of its content before making it scrollable, so
  anything past the first screen was clipped with nothing to scroll, and
  notes were also truncated at 800 characters. The height is now capped
  on the scrolling area and the whole text is shown.

## 🔍 Changed

- **Release notes read as plain text.** The notes are written for GitHub,
  with Markdown markers and hard line breaks, so in the app they showed
  `#` and `**` and broke mid-sentence. Lines are now joined back into
  paragraphs, headings show without `#`, and list items get a bullet.

## 🔧 Internal

- **`scripts/set_release_secrets.sh`.** The tag-triggered "Release APK"
  workflow had no secrets in this repo: they had stayed on the old private
  repo. This one-time script copies them from this PC's local
  configuration into the protected `release` environment, so a tag push
  (from a cloud session, say) can build and publish on its own.

## Install

Update through Autogram's in-app updater.
