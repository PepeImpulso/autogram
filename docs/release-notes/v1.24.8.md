# Autogram v1.24.8

## Fixed

- Prevented incoming reply playback from starting during the short gap between tapping record and the recorder backend reporting an active recording.
- Queued voice and TTS playback while the user is starting or recording an outgoing message.
- Kept the post-recording autoplay drain delayed by two seconds and rechecked recording/playback state before releasing queued audio.

## Validation

- Added regression tests for the recording-start playback gate and the two-second post-recording drain delay.
