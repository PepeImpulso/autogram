# v1.25.7 — Play launch readiness 🚀

This release prepares Autogram for its first Google Play internal test and
keeps first-run controls reachable on edge-to-edge Android devices.

## 🐛 Fixed

- **Kept onboarding controls above system navigation.** The bottom action row
  now respects the navigation-bar inset, preventing Samsung gesture and button
  navigation from covering the Next button.
- **Removed conflicting car declarations.** The Play manifest now advertises
  projected Android Auto support without also claiming Android Automotive OS
  hardware, allowing Play Console to accept the bundle.

## 🔧 Internal

- **Separated distribution identities.** Google Play uses
  `com.impulsotecnologico.autogram`, while the standalone GitHub flavor keeps
  `com.autogram.app` so existing installations continue receiving updates.
- **Hardened Play bundle validation.** The build script rejects unexpected
  application IDs and incompatible Automotive OS declarations before upload.

## Install

The Play build installs separately from the standalone GitHub build and does
not share its local data or Telegram session.
