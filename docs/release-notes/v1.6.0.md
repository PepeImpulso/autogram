# v1.6.0 — Android Auto en serio (M3) 🚗

Tercer milestone del roadmap. Hasta aquí AA solo tenía el launcher
entry; ahora también recibe notificaciones con MessagingStyle +
CarAppExtender, lee mensajes de texto por TTS, y rutea el audio al
altavoz del coche cuando hay un A2DP conectado.

## ✨ Added

- **`IncomingMessageNotifier`** con `NotificationCompat.MessagingStyle`
  + `CarAppExtender`. El head unit del coche ahora surfacea la
  notificación de mensaje entrante con el nombre del sender y el
  preview del texto o "Nota de voz".
- **`TtsPlayer`** (envoltorio sobre `TextToSpeech`) para leer
  mensajes de **texto** entrantes por TTS. Usa el locale UI actual
  (via `AppCompatDelegate.getApplicationLocales`) para la voz.
  Respeta `settings.playbackSpeed`.
- **Grid en AA** con el círculo primario + los secundarios fijados.
  Antes solo aparecía el primary. Ahora cada tile del coche es
  grabable.
- **Rutado Bluetooth preferente**: `AudioPlayer.preferBluetoothRoute`
  detecta `TYPE_BLUETOOTH_A2DP` / `TYPE_WIRED_HEADSET` / `TYPE_BLUETOOTH_SCO`
  (en ese orden de preferencia) y llama `setPreferredDevice` para
  que el mensaje salga por los altavoces del coche, no por el
  del móvil.

## 🔍 Changed

- `MtprotoReceiverService.handleVoiceNote` dispara ahora
  `incomingMessageNotifier.postVoiceReceived` junto al `playVoiceMessage`
  habitual.
- Permisos nuevos en el manifest: **`BLUETOOTH_CONNECT`** (runtime
  en API 31+) para consultar dispositivos de audio conectados.

## Install

Actualización desde 1.5.x. Al conectar el móvil al DHU (desktop head
unit) o al coche, las notificaciones de voz nueva aparecen con
Listen / Reply en la pantalla del vehículo.
