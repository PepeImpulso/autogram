# v1.6.0 — Android Auto for real (M3) 🚗

Third roadmap milestone. Up to this point AA only had the
launcher entry; now it also receives MessagingStyle +
CarAppExtender notifications, reads text messages via TTS, and
routes audio to the car speaker when an A2DP device is
connected.

## ✨ Added

- **`IncomingMessageNotifier`** with `NotificationCompat.MessagingStyle`
  + `CarAppExtender`. The car's head unit now surfaces the
  incoming message notification with the sender name and either
  the text preview or "Voice note".
- **`TtsPlayer`** (wrapper around `TextToSpeech`) to read
  incoming **text** messages via TTS. Uses the current UI locale
  (via `AppCompatDelegate.getApplicationLocales`) for the voice.
  Respects `settings.playbackSpeed`.
- **AA grid** with the primary circle + pinned secondaries.
  Before, only the primary appeared. Now each car tile is
  recordable.
- **Preferred Bluetooth routing**: `AudioPlayer.preferBluetoothRoute`
  detects `TYPE_BLUETOOTH_A2DP` / `TYPE_WIRED_HEADSET` /
  `TYPE_BLUETOOTH_SCO` (in that preference order) and calls
  `setPreferredDevice` so the message plays out of the car
  speakers, not the phone's.

## 🔍 Changed

- `MtprotoReceiverService.handleVoiceNote` now fires
  `incomingMessageNotifier.postVoiceReceived` alongside the usual
  `playVoiceMessage`.
- New manifest permissions: **`BLUETOOTH_CONNECT`** (runtime on
  API 31+) to query connected audio devices.

## Install

Update from 1.5.x. When you connect the phone to DHU (desktop
head unit) or to the car, new voice notifications appear with
Listen / Reply on the vehicle screen.
