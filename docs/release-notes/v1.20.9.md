# v1.20.9 — Gold-on-dark brand refresh

New launcher icon (gold paper plane + microphone over a deep brown
rounded square) and a matching in-app theme. The old Material-blue
palette is gone for good — Autogram now looks the same colour the user
sees on their homescreen.

## Changed

- **Launcher icon** replaced at every density (mdpi 48 → xxxhdpi 192)
  plus the adaptive foreground (mdpi 108 → xxxhdpi 432). Adaptive
  background is now solid brand-brown `#1A120B` so launcher
  circle / squircle / rounded-rect masks all blend cleanly with the
  dark corners of the foreground.
- **In-app theme** switched to the icon's palette:
  `#D4AF37` (gold primary) on `#1A120B` (dark brown) with `#F1D27A`
  highlight accents. Material 3 dynamic-colour is disabled so the
  gold stays gold regardless of the user's wallpaper, and the app
  now always renders in its dark variant for consistency with the
  icon — no more blue surface in light mode.
- **HeroHeader logo** (top-left of the home screen) swapped for the
  new icon.

## Install

Update from Autogram's in-app updater. No schema change, no new
permissions. On Android 12+ the new icon may take a launcher-cache cycle
to refresh — long-press and re-drag from the app drawer if the old
version lingers.
