# v1.19.12 — Updates section moved to top of Settings ⚙️🆙

Small UX rearrangement per user request.

## 🔍 Changed

### Settings → Updates now opens the screen

Previously the **Updates** section card sat near the bottom of
Settings, after Battery. The user wants to see "is my app up to
date?" as the first thing in Settings, not the last. Moved the
Updates section to the very top of the `Column`.

### Title + installed version share one line

The section card title now reads:

> **Updates - Installed version: 1.19.12**

…rather than **Updates** with the version as a separate body
line. Only the "Check for updates" button (plus the transient
status indicator) remains in the card body, matching the user's
request that the button live below the title.

Reuses the existing `settings_updates_section` and
`settings_updates_current_version` strings in all six locales,
concatenated with a " - " separator so the translations still
apply verbatim.

## Install

Update from 1.19.11. UI-only change; no migration.
