# v1.18.1 — Add the NAVIGATION_TEMPLATES permission 🔑

v1.18.0 switched the AA home to a `NavigationTemplate` +
`SurfaceCallback` so we can render a custom layout like Waze. It
crashed immediately on first render with:

```
SecurityException: The car app does not have a required permission:
  androidx.car.app.NAVIGATION_TEMPLATES
```

AA's host enforces that any app using `NavigationTemplate` also
declares the `androidx.car.app.NAVIGATION_TEMPLATES` permission.
The permission is signature-protected by Gearhead so only apps
that declare it are allowed to use the surface-rendering path.

## 🐛 Fixed

- Added `<uses-permission
  android:name="androidx.car.app.NAVIGATION_TEMPLATES" />` to the
  manifest. No other changes.

## Install

Update from 1.18.0. Open AA → tap Autogram; the custom canvas
(big Merlin, stacked chips, secondaries row) should now render
without the crash.
