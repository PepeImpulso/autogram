# v1.3.1 — Fix i18n + default a inglés 🌐🔧

## 🐛 Fixed

- **El idioma seleccionado no se aplicaba de verdad**. El setter
  escribía en settings pero `AppCompatDelegate.setApplicationLocales`
  no se llamaba en el sitio correcto, así que hasta forzar un cierre
  completo de la app no se veía el cambio. Ahora el cambio es
  inmediato tras tap.
- **Default ahora es inglés** en vez del idioma del sistema. El
  comportamiento antiguo hacía que un usuario con móvil en francés
  viera UI en francés sin haberlo elegido; ahora fresh install
  siempre arranca en inglés, y tú lo cambias a lo que quieras.
