# v1.3.1 — i18n fix + default to English 🌐🔧

## 🐛 Fixed

- **The selected language wasn't actually being applied**. The
  setter wrote to settings but `AppCompatDelegate.setApplicationLocales`
  wasn't called in the right spot, so until you force-closed the
  app the change wasn't visible. Now the change is immediate
  after tap.
- **Default is now English** instead of the system language. The
  old behavior meant a user with a French phone saw a French UI
  without having chosen it; now fresh installs always start in
  English, and you change it to whatever you want.
