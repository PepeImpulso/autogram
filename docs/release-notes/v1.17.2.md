# v1.17.2 — Autogram no longer crashes inside Android Auto 🚗🔧

Follow-up to v1.17.1, which made the app tile visible in the Auto
launcher but tripped an assertion the moment the user opened it.
Caught via the Desktop Head Unit emulator against the same APK the
user has on the phone.

## 🐛 Fixed

- **`IllegalArgumentException: Action list exceeded max number of 1
  actions with custom titles`** on both the main screen and the
  recording screen. The AA template API enforces that **at most one
  `Action` in any `ActionStrip` / template action list may have a
  `setTitle(...)`**; the rest must be icon-only.

  Fixes:

  - `MainScreen.buildActionStrip()`: kept the title on the
    **Voice command** action (primary CTA), dropped the title from
    the **silent toggle** — the speaker icon + yellow tint when
    muted conveys state unambiguously.
  - `MainScreen.buildRecordingTemplate()`: kept the title on
    **Stop and send** (primary), dropped the title from the
    **Cancel** action — the red X icon is universal.

  Without this the CarAppService crashed every time AA tried to
  render the home screen, and AA kept respawning the service
  forever until it gave up.

- **Hardcoded Spanish "Volver"** in the status-reset action of the
  recording-complete screen. Replaced with
  `R.string.common_back`, which is already localized to all 6
  supported locales.

## Install

Update from 1.17.1. Open Android Auto, tap the Autogram tile —
the home screen should now render (Merlin circle + pinned
circles + action strip) without crashing.
