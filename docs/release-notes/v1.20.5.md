# v1.20.5 — Android Auto release hardening

This release tightens the Android Auto launch path and the GitHub updater
flow so new builds can be tested through Autogram's in-app update button.

## Fixed

- **Android 10-13 foreground startup** now starts the MTProto receiver with
  the compatible `dataSync` foreground-service type instead of Android 14's
  `specialUse` type.
- **Android Auto host validation** no longer depends on a private AndroidX Car
  resource; Autogram carries its own release-host allowlist.
- **GitHub release notes in CI** now use Autogram's checked-in release notes
  when present, so the updater shows the intended notes instead of generated
  GitHub text.

## Tests

- **Release and debug checks** cover the updater semver comparator, including
  stable-vs-prerelease ordering and numeric prerelease suffixes.

## Install

Update from Autogram's in-app updater; Android Auto testing should use this
published release rather than a locally copied APK.
