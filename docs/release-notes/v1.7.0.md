# v1.7.0 — Onboarding & backup (M6) 🎓

Sixth roadmap milestone. First-time wizard in 4 screens + an
encrypted backup/restore system for the user's configuration.

## ✨ Added

- **`OnboardingActivity`** — 4-screen wizard (welcome,
  press-and-hold gesture, pick main recipient, shortcuts). It
  launches from `MainActivity.onResume` if
  `settings.onboardingCompleted = false`.
  - Fresh install: wizard runs once, gets marked as completed.
  - Upgrade: the v8→v9 migration sets `onboardingCompleted = true`
    by default, so existing users don't see it.
- **`ExportImportUseCase`** — encrypted export/import of the
  configuration:
  - **Format**: `AUGBKP01` (8-byte magic) + 16-byte salt +
    12-byte IV + encrypted payload (UTF-8 JSON).
  - **Crypto**: AES-256-GCM with key derived by PBKDF2-HMAC-SHA256,
    100,000 iterations. 128-bit auth tag.
  - **What gets exported**: `AppSettings`, `QuickReply[]`,
    `Conversation[]` (without secrets), circle photos in base64.
  - **UI**: Settings → Backup → Export / Restore. Export opens
    SAF with suggested filename `autogram-backup-YYYYMMDD-HHMM.autogram`.
    Import asks for password + confirmation before overwriting.

## 🔍 Changed

- DB migration **v8 → v9** (non-destructive): adds
  `settings.onboardingCompleted` with default `1` (upgrades) and
  `0` (fresh install via entity default).

## Install

Update from 1.6.x. Existing users don't see the wizard. To
export your configuration for the first time: Settings → Backup
→ Export, pick a password and destination folder.
