# v1.7.0 — Onboarding & copia de seguridad (M6) 🎓

Sexto milestone del roadmap. Wizard de primera vez en 4 pantallas
+ sistema de backup/restore cifrado para la configuración del
usuario.

## ✨ Added

- **`OnboardingActivity`** — wizard de 4 pantallas (bienvenida,
  gesto press-and-hold, elegir destinatario principal, accesos
  rápidos). Se lanza desde `MainActivity.onResume` si
  `settings.onboardingCompleted = false`.
  - Fresh install: wizard corre una vez, se marca como completado.
  - Upgrade: la migración v8→v9 pone `onboardingCompleted = true`
    por defecto, así que los que ya usaban la app no lo ven.
- **`ExportImportUseCase`** — export/import cifrado de la
  configuración:
  - **Formato**: `AUGBKP01` (8 bytes magic) + 16 bytes salt +
    12 bytes IV + payload cifrado (JSON UTF-8).
  - **Crypto**: AES-256-GCM con clave derivada por PBKDF2-HMAC-SHA256,
    100 000 iteraciones. Tag de autenticación 128 bits.
  - **Qué se exporta**: `AppSettings`, `QuickReply[]`,
    `Conversation[]` (sin secretos), fotos de círculos en base64.
  - **UI**: Ajustes → Copia de seguridad → Exportar / Restaurar.
    Export abre SAF con filename sugerido `autogram-backup-YYYYMMDD-HHMM.autogram`.
    Import pide contraseña + confirmación antes de sobrescribir.

## 🔍 Changed

- Migración de DB **v8 → v9** (no destructiva): añade
  `settings.onboardingCompleted` con default `1` (upgrades) y `0`
  (fresh install vía entity default).

## Install

Actualización desde 1.6.x. Los usuarios existentes no ven el
wizard. Para exportar la configuración por primera vez: Ajustes →
Copia de seguridad → Exportar, eliges contraseña y carpeta de
destino.
