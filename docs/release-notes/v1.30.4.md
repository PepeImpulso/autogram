# v1.30.4 — Compact pause / next in the car 🚗

The car's pause / resume and next buttons no longer take up as much room
as a contact.

## 🐛 Fixed

- **Pause and Next were giant tiles on the car screen.** Android Auto draws
  every item in the Grabar grid at contact size, so the two playback
  buttons that appear while a message plays looked like two more contacts.
  They are now compact rows (small icon and label) under the contacts.
  Android Auto doesn't let media apps add their own buttons to the top bar.
  The car's own "now playing" button there still opens the player with the
  same controls.

## Install

Update through Autogram's in-app updater.
