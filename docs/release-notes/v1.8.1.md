# v1.8.1 — Security + concurrency audit 🔒

Security and concurrency audit of the code accumulated across
M1-M6. 10 real defects fixed — 3 critical, 5 high, 2 medium.

## 🐛 Fixed (critical)

- **Backup PBKDF2 iterations 100k → 600k**. 100,000 was the
  recommended value in 2020; NIST SP 800-132 in 2024 requires
  ≥ 600,000 for SHA-256. New magic `AUGBKP02` identifies v2
  files (600k); backups written by 1.7.x (`AUGBKP01`, 100k) can
  **still be imported** so no data is lost. New exports are
  always v2.
- **Password in memory**: the String from Compose state + the
  CharArray from CharArray transfer can linger until GC.
  Explicit clear on dismiss + unmount + zeroization of the
  CharArray after `deriveKey`. `SecretKeySpec` key material
  also zeroized via reflection.
- **`ParcelFileDescriptor` leak** in
  `AndroidOnDeviceTranscriptionEngine`: cancellation could race
  with `settle()` and leave the fd open. Now guarded with
  `AtomicBoolean` + CAS — cleanup runs exactly once regardless
  of who wins the race.
- **MediaCodec decoder leak** if OGG decoding aborts mid-way.
  try/finally cleans up codec + extractor + temp file.

## 🐛 Fixed (high)

- **Race in `PlayReplyUseCase`** between two concurrent
  `playVoiceMessage` calls. `kotlinx.coroutines.sync.Mutex`
  serializes the "start playing" critical section.
- **`TtsPlayer.shutdown()`** was never called. Now hooks into
  `Application.onTrimMemory` — when the UI is hidden, we release
  the TTS engine. The next `speak` recreates it lazily.
- **`MtprotoReceiverService`** re-entrant onDestroy could cancel
  a freshly created scope. A `destroyed` flag guards it.
- **`ConnectivityObserver`** registered the callback AFTER the
  first `trySend(currentSnapshot())`; changes between the two
  calls got lost. Order reversed.

## 🐛 Fixed (medium)

- **Sentry PII scrubber**: `beforeSend` + `beforeBreadcrumb`
  strip phone numbers and long IDs (chat/message IDs).
  Additionally `isSendDefaultPii` is disabled and `event.user`
  and `event.request` are nulled.
- **`ExportImportUseCase.import`** validates the JSON's
  `schemaVersion` — backups from future versions with fields we
  don't know how to handle surface as `UnsupportedVersion`
  instead of `Corrupt`.

## Install

Update from 1.8.0. Backups you made before (`AUGBKP01`) can
still be imported; from now on new ones are `AUGBKP02` with 6x
the brute-force cracking cost.
