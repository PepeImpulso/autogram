# v1.18.3 — AA polish: Merlin top-left + thinner gold ring 🎨

Small tuning pass on top of v1.18.2's custom canvas. User liked
the layout but asked for two tweaks.

## ✨ Changed

- **Merlin flush with the top-left margin**. The primary circle
  used to sit ~32% into the content area vertically (optically
  centred). Now its top edge aligns with the content top and
  the left edge sits one tile-gutter from the surface left
  margin. Frees vertical space for the secondaries row and
  matches the phone's layout where Merlin anchors the top-left.
- **Shortcut chips re-aligned to Merlin's new span**. The
  vertical chip stack now covers Merlin's full top→bottom
  height instead of stopping at 60% down, so no dead space
  appears above the first chip.
- **Thinner gold ring on every avatar**. Stroke reduced from
  7–8% to **4% on the primary, 5% on secondaries** of the ring
  radius. Reads as an accent instead of a heavy frame.

## Install

Update from 1.18.2. No behaviour changes, purely visual.
