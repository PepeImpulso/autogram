# v1.20.8 — Spanish voice (real fix), transcribe text + keep-screen-on

v1.20.7 wasn't enough — Spanish replies were still being read with an
English voice. The root cause turned out to be in the engine, not the
detector. This release also clarifies the Transcription setting copy and
adds an opt-in keep-screen-on toggle.

## Fixed

- **Spanish text now actually plays in a Spanish voice.** The previous
  release set `tts.language = es` and trusted the engine to follow,
  but Google TTS keeps whatever `Voice` it loaded last — so the engine
  said "Spanish accepted" while still synthesising in English. Autogram
  now enumerates the engine's installed voices, picks one whose
  `voice.locale.language` matches the detected language and isn't
  marked NOT_INSTALLED / network-only, and assigns `tts.voice` directly.
  `setLanguage` is still called as a fallback for engines that ignore
  `setVoice`. Every speak() call logs the picked voice's name + locale
  + quality so you can confirm it from `adb logcat` if it ever drifts
  again.

## Changed

- **Transcription settings copy** no longer says "Google speech language
  pack" (vague — there's no single such pack). It now spells out the
  three things needed: Android 14+, Google's on-device speech
  recognition, and a downloaded language pack for the message's
  language, with the exact path to install one (Android Settings →
  System → Languages → On-device speech recognition). The duplicated
  "Transcribe voice messages" header has been replaced with a category
  header so the section title and the toggle label aren't identical.

## Added

- **Keep screen on** toggle in Settings → Playback. When on, the home
  screen ignores the system screen-timeout so the app stays visible
  while listening to a queued reply or watching for the next message.
  Off by default — the trade-off is faster battery drain.

## Install

Update from Autogram's in-app updater. Existing TTS data is reused
as-is; no new permissions. The schema migrates 14 → 15 with a one-line
ALTER on `settings`.
