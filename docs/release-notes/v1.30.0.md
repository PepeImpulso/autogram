# v1.30.0 — Pause and skip from Home and the car grid ⏯️⏭️

While a message is playing you can now pause it, resume it, or jump to the
next one without leaving the Home screen, on the phone and in the car.

## ✨ Added

- **Pause / resume and Next buttons on the phone's Home.** While a message
  is playing or paused, two round buttons appear in the header next to the
  stop button: ⏸ pauses (tap again ▶ to resume where it stopped) and ⏭
  skips to the next queued message. They hide again when nothing is
  playing, so the header stays as before the rest of the time.
- **Pause / resume and Next tiles on the car grid.** While a message is
  playing or paused, the Grabar grid shows "Pause" (or "Resume") and "Next
  message" tiles right after the contacts, so the contacts keep their
  places. Android Auto opens its player when any tile is tapped; that
  player already has the same pause and next controls. If the queue is
  empty, Next just stops the current message.

## Install

Update through Autogram's in-app updater.
